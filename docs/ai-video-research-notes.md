# AI 영상 제작 리서치 노트 (2026-08-30)

사장님이 공유한 유튜브 링크 중 "지금 채널에 바로 쓸 만한 것" 위주로 6편을 살펴보고
뽑아낸 실전 기법입니다. 전체 25개 링크를 다 본 건 아니고, 캐릭터 일관성 · 훅/편집
팁 · 블로그→유튜브 전환 관련만 추렸습니다. 나머지(영화 제작 8가지 비법, 클라우드/사운드
디자인 등)는 필요해지면 추가로 조사합니다.

## 1. "핸드헬드 + 브이로그" 프롬프트 트릭
- 출처: 특이점이 온다 — "딱 2단어만 넣으면, 모든 AI 영상이 자연스러워집니다"
- 내용: Seedance 2.5 같은 영상 생성 모델에 `handheld`(손으로 든 듯한 흔들리는 카메라),
  `vlog`(브이로그 톤) 두 단어를 프롬프트에 넣으면 AI 특유의 "너무 매끈해서 가짜 같은" 느낌이
  줄고 훨씬 자연스러워진다는 실전 팁. 댓글 반응도 실제로 효과 있다는 쪽이 많음.
- **적용 시점**: 우리가 실제 영상 생성 AI(Veo/Seedance 등 유료 API)를 쓰기로 결정하면 바로
  프롬프트에 넣을 수 있음. 지금(ffmpeg+정지이미지) 단계에서는 해당 없음.

## 2. 캐릭터 일관성 — "9프레임 캐릭터 시트" 방식 (구글 Flow / Veo Omni)
- 출처: 원카AI Wonka — "프롬프트 하나로 영상 9개 뽑는다고?! 구글 Veo Omni와 Flow 2026 업데이트"
- 내용: 캐릭터(예: 엄마 고양이 + 아기 고양이)의 각기 다른 장면 9컷을 3x3 그리드 한 장의
  "캐릭터 시트" 이미지로 만들어 참조 이미지로 첨부하면, 프롬프트 한 번으로 같은 캐릭터가
  9개 장면에 일관되게 등장하는 영상들을 뽑아낼 수 있음.
- **적용 시점**: 우리 사주 릴스가 "매번 같은 얼굴(캐릭터)"을 채널 브랜드로 쓰고 있다는 점과
  정확히 맞닿음([sajuReels.js:9](src/sajuReels.js:9) 주석 참고). 지금은 SVG 그라디언트 배경이라
  캐릭터 자체가 없지만, 나중에 실제 캐릭터 일러스트/AI 인물을 쓰기로 하면 이 "캐릭터 시트"
  방식이 일관성 유지의 핵심 기법이 됨. 이것도 실제 생성 모델(유료) 사용을 전제로 함.

## 3. 클로드 데스크탑 + Remotion으로 "블로그 글 → 영상" 자동화
- 출처: 알파GOGOGO — "AI 활용 300% 하는 방법 | 클로드로 영상 만들기"
- 내용: 클로드 데스크탑 앱과 Remotion(React 기반 프로그래매틱 영상 프레임워크)을 연동해서
  블로그 글 텍스트를 영상으로 자동 변환하는 워크플로우.
- **적용 시점**: 지금 바로 유효함 — 사장님이 이미 골든 블로그 에디터(8485 포트)로 원고를
  대량 생산 중이므로, "블로그 원고 → Remotion 영상" 파이프라인을 만들면 완전히 새로 대본을
  안 써도 기존 콘텐츠를 영상으로 재활용 가능. 지난번 설치한 `remotion-video-creation`,
  `remotion-video-toolkit`, `remotion-video` 스킬이 바로 이 용도.

## 4. Claude Code + Remotion 자동화 사례 확인
- 출처: @halfdoneclubai — "클로드 디자인, 500만뷰 카드뉴스 자동화 플로우"
- 내용: "클로드 코드 x 리모션 영상 자동화(팀 소개, 제품/서비스 홍보, 숏츠)"를 표방하는 채널.
  우리가 하려는 방향(Claude Code로 코드 기반 영상 자동화)이 이미 실제로 쓰이고 있다는 확인
  차원의 레퍼런스.

## 5. 편집 도구 레퍼런스
- Vrew — 자막 자동 생성/편집 툴. 왕초보 대상 강의 영상에서 자주 언급됨(#vrew). 우리는 이미
  ffmpeg+libass로 자막을 자동 생성하고 있어서 당장 필요는 없지만, 사람이 손으로 컷 편집할
  일이 생기면 참고할 만한 무료 툴.

  준비해뒀습니다.

## 7. Voicebox — 실체 확인 + 실전 가이드 (2026-08-30, 관련 영상 10편 추가 확인)

`voicebox.sh` 공식 사이트와 문서를 직접 확인했습니다. 유튜브 영상들이 말한 "보이스박스"는
실제로 존재하는 오픈소스 프로젝트였습니다.

**정체**: ElevenLabs의 무료 오픈소스 대안. MIT 라이선스, **완전 무료, 평생 무료**.
GitHub 스타 5.19만 개, 누적 다운로드 238만+. macOS(Apple Silicon/Intel) · Windows · Linux 지원.

**핵심 특징**
- **100% 로컬 실행** — 클라우드로 전송되는 것 없이 내 컴퓨터 안에서 전부 처리. API 키도,
  건당 비용도, 사용량 제한도 없음.
- 목소리 샘플 **3초**만 있어도 복제 가능(마이크로 최대 30초 녹음 / 파일 업로드 / 시스템
  오디오 캡처 3가지 방법 지원).
- TTS 엔진 7종 중 골라서 사용 — 예: **Qwen3-TTS**(알리바바, 다국어 자연스러운 억양 +
  톤·속도·감정을 자연어로 지시 가능), **Chatterbox**(Resemble AI, 23개 언어 지원, 제로샷
  복제), **Kokoro**(82M 초경량, CPU만으로도 실시간).
- 한 번에 최대 5만 자까지 생성(문장 단위로 자동 분할 후 이어붙임) — 롱폼 대본 나레이션도
  통으로 가능.
- **로컬 REST API 내장**(`http://127.0.0.1:17493`) — `POST /generate`에 텍스트+프로필 ID를
  보내면 바로 오디오 파일이 응답으로 옴. 코드에서 그대로 호출 가능.
- **MCP 지원** — Claude Code 같은 MCP 에이전트를 Voicebox MCP 서버에 연결하면
  `voicebox.speak({text, profile})` 툴 호출 한 번으로 제가 직접 사장님 목소리로 말하게 만들
  수 있음.

**설치·설정 방법 (사장님이 직접 하셔야 하는 부분 — 마이크 녹음은 대신 할 수 없어요)**
1. https://voicebox.sh 접속 → Windows용 설치 파일(MSI) 다운로드해서 설치
2. 앱 실행 → "Create Voice"(또는 Capture) → 마이크로 3~30초 내 목소리 녹음, 또는 기존
   음성 파일 업로드해서 목소리 프로필 생성
3. 원하는 TTS 엔진 선택(한국어면 Qwen3-TTS 또는 Chatterbox 추천 — 다만 정확히 어떤 언어가
   포함되는지는 앱 안에서 직접 확인 필요, 공식 페이지엔 "다국어"라고만 나와 있고 언어
   목록이 명시돼 있지 않음)
4. 만들어진 프로필의 ID 확인(앱 UI에서 보이거나, Voicebox 실행 중 `GET http://127.0.0.1:17493/profiles`
   호출로도 확인 가능)
5. 이 프로젝트의 `.env`에 `VOICEBOX_PROFILE_ID=<그 ID>` 추가

**코드 연동은 이미 준비해뒀습니다**: [src/voiceProvider.js](src/voiceProvider.js)에 5번째
제공자로 `voicebox`를 추가했습니다. `VOICEBOX_PROFILE_ID`만 채우면 `renderShortformVideo()`
호출 시 `voice: { provider: "voicebox" }`로 넘겨서 바로 사장님 목소리로 나레이션이 만들어져요.
단, **Voicebox 앱이 실행 중인 그 컴퓨터에서 렌더를 돌릴 때만 동작**합니다 — Render.com 같은
원격 서버는 Voicebox가 설치돼 있지 않아서 안 됩니다. 즉 로컬에서 영상 만들 때 전용입니다.
- **HyperFrames 확인됨**: 지난번 설치한 `general-video`/`product-launch-video` 등이 속한
  heygen-com/hyperframes 스킬이 실제로 "클로드 코드 + HyperFrames" 조합으로 여러 유튜버가
  쓰고 있는 실전 툴임을 재확인.
- **캐릭터 일관성 워크플로 구체화**: cocojuan "Veo 3.1 캐릭터 일관성 문제 해결" —
  Nano Banana Pro(이미지 생성)로 캐릭터 시트·장면 시트를 먼저 만들고, 그걸 Veo 3.1에 넣어
  시네마틱 퀄리티 영상을 뽑는 구체적 2단계 워크플로. (5번 항목의 "9프레임 시트"와 같은 계열.)
- **무료 AI 영상 툴 옵션들**: Google VIDS(구글 문서도구처럼 무료), 구글 Flow 무료 모델 비교,
  TopView MCP, Higgsfield MCP + Claude Opus5(종이 질감 모션그래픽을 프롬프트 한 줄로) —
  전부 "유료 생성 API 없이 또는 최소 비용으로" 영상을 만드는 경로들. 실제 전환 전에 각각
  무료 한도/화질을 비교해봐야 함.
- **롱폼 관련**: "클로드 코드로 영화 리뷰 영상 대본 쓰는 법" — 영화 리뷰 롱폼 채널이 4년간
  23억 매출을 냈다는 사례와 함께, 대본 작성을 클로드 코드로 80% 자동화하는 흐름 소개.
  지금 우리는 숏폼(사주 릴스) 위주인데, 대본 자동화 자체는 롱폼에도 그대로 적용 가능.
- **Apify 커넥터**: "클로드로 유튜브 만드는 순서 전부 공개합니다" — 리서치/데이터 수집 단계에
  Apify(웹 스크래핑 자동화 플랫폼)를 MCP로 연결해서 쓰는 사례. 트렌드 리서치 자동화에 참고.
- **모션그래픽 대안**: "애프트이펙트 없이 AI 모션 그래픽 구글 플로우로" — After Effects 없이
  텍스트+이미지+AI 프롬프트만으로 2D 모션그래픽 오프닝 제작. 한글도 된다고 함.

## 결론 — 지금 뭘 바꿀 수 있나

| 기법 | 지금 파이프라인에 적용 가능? | 비용 |
|---|---|---|
| 핸드헬드+브이로그 프롬프트 | ❌ (정지이미지+ffmpeg라 해당 없음, Veo/Seedance 쓸 때 유효) | 유료 API 필요 |
| 캐릭터 시트(9프레임) | ❌ 지금은 캐릭터가 없음. 나중에 실사/일러스트 캐릭터 도입 시 핵심 기법 | 유료 API 필요 |
| 블로그→Remotion 영상 자동화 | ✅ 지금 바로 시작 가능. 골든 블로그 원고를 재료로 씀 | 무료(로컬 렌더) |
| Claude Code+Remotion 자동화 | ✅ 참고 사례로 확인됨, 방향성 검증 | 무료 |
| **Voicebox 무료 목소리 복제** | ✅ 코드 연동 완료(`voiceProvider.js`). 사장님이 앱 설치+녹음만 하면 바로 사용 가능 | **완전 무료(로컬)** |
| Vrew | 참고용, 당장 불필요 | 무료 |

**다음으로 진행하면 좋은 것**: Voicebox는 사장님이 앱을 설치하고 목소리를 녹음해주셔야
(이 부분은 제가 대신 할 수 없는 영역이에요) 실제로 켜집니다. 그 전까지는 3번(블로그→Remotion
자동화)이 지금 가진 자산(블로그 원고 대량 생산 시스템)을 그대로 활용할 수 있는 가장 현실적인
다음 단계입니다.
