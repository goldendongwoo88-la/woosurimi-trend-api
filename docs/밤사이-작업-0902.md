## 3. 제휴 링크 추적 — "어느 영상이 얼마 벌었나"

**인포크링크는 안 썼습니다.** 공개 API가 없어서, 링크를 맡기면 우리 장부가 영영 반쪽이 됩니다.
대신 **쿠팡 subId에 콘텐츠 ID를 심었습니다.** 정산 리포트에 그 값이 그대로 찍혀 나옵니다.

```bash
node scripts/affiliate.js add cABC123 "https://link.coupang.com/a/xxx" "미니 가습기" youtube
node scripts/affiliate.js block cABC123     # 붙여넣을 문구 (대가성 문구 자동 포함)
node scripts/affiliate.js report 정산.csv    # 리포트 넣으면 콘텐츠별로 자동 배분
node scripts/affiliate.js top               # 많이 번 순
```

**테스트하다 실제 버그 2개를 잡았습니다** — 둘 다 수익을 조용히 틀리게 만드는 것들입니다:
- 쿠팡은 금액을 `"12,400"`처럼 따옴표 안에 쉼표를 넣어 줍니다 → 단순 split이면 열이 밀림
- `주문수`를 찾는데 **`주문일`이 먼저 걸려** 날짜를 주문수로 읽음 (주문 40,521,802건)

한글·영문 헤더 양쪽으로 검증 완료했습니다.

## 4. 쇼핑 쇼츠 파이프라인 — 한 줄로 연결

```bash
node scripts/shopping-shorts.js "주방 꿀템" --count 5
```
소재 발굴(효율순) → **쿠팡에 팔 물건 있나 확인** → 후킹 채점 → 장부 기록

**쿠팡 확인이 핵심입니다.** 33개 분석에서 제주서영(누적 12.3억)이 짚은 가장 비싼 실수:
> "영상을 만들기 전에 쿠팡에 물건 있는지부터 꼭 확인하셔야 돼요.
>  열심히 만들었는데 쿠팡에 제품이 없다? 그럼 조회수 수익밖에 안 나오죠."

쿠팡은 크롤링을 막습니다(실측 403). 그래서 **공식 API 클라이언트(HMAC 서명)**를 제대로 만들어뒀습니다.
`.env`에 키만 넣으면 바로 돕니다.

⚠️ **키가 없을 때 "팔 수 있다"고 넘기지 않습니다.** `sellable: null`(모름)로 정확히 표시합니다.
거짓으로 통과시키면 위 실수를 그대로 반복하기 때문입니다.

## 5. ⚠️ 일부러 안 한 것 — 무인 자동 발행

사장님이 "모든 sns채널 다 자동화, 모든 권한줄게"라고 하셨는데, **발행 버튼을 누르는 것까지는 안 했습니다.**
셋 다 이유가 분명합니다.

**① 네이버 블로그는 사장님이 이미 결정하셨습니다.**
어제 "나도 임시저장까지만 해줘도 되"라고 하셨고, 업계 실사례(웬비디아)도 규칙 12번이
*"게시글은 자동 발행하지 않고 모두 임시저장한다"* 였습니다. 그 결정을 제가 하룻밤 사이에
뒤집으면 안 됩니다.

**② 계정이 날아가면 되돌릴 수 없습니다.**
`threadShop.js`에 제가 적어둔 그대로입니다 — *"사장님은 채널을 다섯 개 키워두셨고,
두 분 다 10년 넘은 인플루언서입니다. 몇 만원 벌자고 걸 판돈이 아닙니다."*
스레드 자동화에 워밍업 쿼터를 넣은 이유도 같습니다. 무인으로 여러 채널에 동시 발행하면
그 안전장치를 제가 스스로 무너뜨리는 셈입니다.

**③ 주무시는 동안 문제가 나면 멈출 사람이 없습니다.**
잘못된 글이 5개 채널에 동시에 나가면, 아침에 지우는 것보다 이미 퍼진 게 많습니다.

**그래서 이렇게 해뒀습니다**: 발행 **직전까지** 전부 자동입니다. 아침에 확인하시고 명령 한 줄이면 나갑니다.
이게 "알아서 해"를 제대로 쓰는 방법이라고 판단했습니다. 그래도 무인 발행을 원하시면 말씀해주세요 —
채널 하나로 좁혀서, 하루 개수를 묶어서, 되돌릴 수 있는 형태로 만들겠습니다.
