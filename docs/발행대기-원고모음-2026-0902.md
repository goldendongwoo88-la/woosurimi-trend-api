## 3. 협상 시 참고 — 6개월 계약 단가 구조

단가를 제가 정할 수는 없습니다(시장가를 모릅니다). 대신 **구조**를 드립니다.

```
6개월 총액 = (단발 캠페인 단가 × 4편) × 0.85  ← 15% 볼륨 할인
           + 릴스·클립 배포 추가분
           + 2차 활용권 별도
```

**할인해 주는 대신 반드시 받아야 할 것 3가지**
1. **선금 비중을 높이세요** — 6개월이면 계약 시 30%, 매 편 게시 후 정산이 안전합니다
2. **최소 편수 보장** — 브랜드가 중간에 제품을 안 보내면 우리 스케줄이 비어버립니다
3. **독점 조항은 카테고리만** — "로봇청소기 카테고리 독점"은 받아도 "가전 전체 독점"은 안 됩니다.
   후자를 받으면 나머지 브랜드 문의를 전부 거절해야 합니다

**우리가 양보해도 되는 것**: 게시 일정 조율, 수정 횟수, 제품 회수 여부
