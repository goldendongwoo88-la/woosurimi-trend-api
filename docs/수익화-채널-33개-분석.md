## ② 양산형 쇼츠 조회수 — 채널을 자산으로

**마라 (11개월 누적 5억)**: 채널 최대 30개 운영, 본인은 **10개월째 영상을 안 만든다.**
기획만 하고 편집은 프리랜서 외주(건당 1만~1.5만원).

**핵심 개념 — 중복도·일치율**
- 유튜브 스튜디오 → **콘텐츠 감지** 탭에서 내 영상의 원본 일치율이 뜬다
- 90~100%면 그대로 퍼온 것 → 위험
- **충분히 재각색하면 유튜브가 수익 창출을 인정한다**

**"터진 건 또 터진다" 3단계 공식**
1. 터진 영상을 고른다
2. **가져오는 타이밍이 있다** — VidIQ 확장으로 조회수 추이를 보고, **성장이 멈춰 평평해진 영상**을 고른다
   (아직 오르는 중이면 유튜브가 계속 밀어주는 중이라 겹친다)
3. 1년 전 것이면 사람들 기억에서 흐려져 **새 영상처럼 먹힌다**

**재각색 방법**: 원본의 **베스트 댓글**을 읽어 사람들이 감동한 지점을 찾고, 그 지점을 **맨 앞으로** 뺀다.
TTS 대본을 새로 얹고, 장면 순서를 바꾸고, 같은 장면은 **3초 이상 안 쓴다**.

## ③ 일본·해외 쇼츠 (번역 재가공)

**머니스트 (1년반 1.5억)**: *"물고기는 많은데 낚시꾼이 없다."*
일본 인구는 한국의 2.4배인데 **부업 문화가 약해 공급자가 적다.**
미국을 안 하는 이유: 영어권은 여러 나라가 공유해서 **유튜브가 미국으로만 노출시켜주지 않는다.**

**소재 발굴**: 플레이보드(playboard) → 차트 → 국가 일본 → 조회수순.
*"상위권에 한국인들이 이미 조용히 돈 벌고 있다."*

**자막 따는 법**: 쇼츠 URL의 `/shorts/`를 **`/watch?v=`로 바꾸면** 롱폼 화면이 되고 → 더보기 → **스크립트 표시**로 대본이 그대로 나온다.

**샤샤롱 (9개월 2.4억, 영상 1개로 1.6억뷰·1,550만원)**
- 카테고리: **유명인 얼굴 + 노래 + 찬양 자막**. 길이 **9~10초**
- 시청지속률 **150~240%** (짧아서 반복 시청)
- 저작권: 유튜브 검색 필터 → **크리에이티브 커먼즈**만 사용
- 논리: *"기획사가 돈 주고 하는 바이럴을 우리가 공짜로 해 주는 것"* → 칭찬만 한다
- 자막이 빨리 지나가도 괜찮다 → **되감아 다시 보므로 시지율이 올라간다**
- 일본어 자막 자르는 법: 조사 **の(노)**, **は(와)** 뒤에서 끊으면 자연스럽다

**박준휘 (영상 1개 → 5군데)**: 유튜브·**카카오 숏폼**·틱톡·**네이버 클립**·인스타
- 카카오 숏폼: 월 200만원 (신규 시장, 경쟁 적음)
- 네이버 클립: 수강생이 월 350만원
- 길이는 **35초 전후**가 최적 (짧으면 반복시청, 길면 완주율 — 그 중간)
- ⚠️ 저작권 판별 팁: **최상단 댓글에 업체가 "이 영상 재밌어요" 달아둔 것** → 십중팔구 라이선스를 사간 영상이니 피한다

## ④ AI 롱폼 (야담·시니어·경제) — 조회수 단가 최고

**RPM(조회수 1당 수익)이 결정적**: 시니어 타겟은 **조회수 1당 약 10~12원**.
이유: 5070은 자금력이 있어 **광고 단가가 높다.** 롱폼은 **중간광고 슬롯이 많이 붙는다.**

| 사례 | 실적 |
|---|---|
| 행크(민담·야담) | 월 5,000만원, 채널 4개 |
| 강피디(시니어 건강) | 한 채널 1억7,600만원 누적, 월 1천만 이상 |
| 개발남 노씨(경제) | 월 1,600만원, 채널 6개 |

**개발남 노씨의 자동화 파이프라인** (우리와 가장 가까움)
1. **유튜브 파인더** 자체 제작 — 키워드·영상길이·최근14일로 검색해 **구독자 대비 조회수(효율)** 높은 것만 추림
2. 레퍼런스 URL 여러 개 + **뉴스 링크**를 클로드 코드에 넣어 대본 생성 → **수치 팩트체크 자동**
3. 대본 → TTS → 그림체 선택 → **스토리보드 자동 분할** → 이미지 일괄 생성 → 영상화 → **5초만에 편집 완료**
4. 썸네일: 잘 터진 것들을 분석해 **미리캔버스 템플릿화**, 이미지만 갈아끼움
5. ⚠️ *"그냥 시키면 안 된다. 사람이 하는 워크플로우 그대로 절차를 하나하나 지침으로 줘야 한다."*

**채널이 날아가는 기준 (여러 명이 일치)**
- 이미지만 슬라이드쇼 → **기계 생산으로 판정**되어 위험
- **동영상**을 넣고, **아바타(헤이젠 등)로 사람처럼** 만들면 안 걸린다 (강피디 5년간 0건)
- 행크: *"AI가 전부 만들었냐, AI를 도구로 썼냐의 차이"*
- 업로드 시 **AI 사용 표시 반드시 체크**

# 2부 · 33편 전체에서 반복된 공통 원칙 6가지

### 1. "터진 건 또 터진다" — 창작하지 말고 검증된 것을 가져와라
거의 모든 사례가 같은 말을 한다. 마라: *"검증받은 영상에 검증받은 댓글을 가져와 재각색."*
박준휘: *"미국에서 터졌으면 일본·한국에서도 무조건 터진다."*

### 2. 감이 아니라 데이터
링밥: *"내 눈에 예뻐 보이면 남도 그럴 거라는 건 뇌피셜."* → 인스타 계정 1,500~2,000개를 실시간 수집해 **대본 30만 개를 분석**하는 프로그램을 직접 만듦.
제주서영: *"많은 데이터를 보면 실력이 쌓인다. 내 감각은 타고난 게 아니라 많이 보고 배운 것."*

### 3. 썸네일·제목·훅·인트로가 8할
개발남 노씨: *"대본은 후순위다. 제일 중요한 건 썸네일·제목·훅·인트로."*
행크: *"영상은 잘 만드는데 돈을 못 버는 사람들이 내용에 집중한다. 힘의 8할은 썸네일과 인트로에 써야 한다."*
→ **사장님이 이미 세운 원칙(80%는 제목·썸네일)과 정확히 일치한다.**

### 4. AI는 도구, 사람 손이 들어가야 채널이 안 날아간다
행크: *"AI가 전부 만들었냐, AI를 도구로 썼냐의 차이."*
강피디: 이미지 슬라이드쇼는 위험 → **동영상·아바타**로.
박준휘: *"유사 구조·양산 구조가 보이는 순간 날린다."*

### 5. 꾸준함이 진짜 해자
머니몬스터: *"두 달 지나면 없어져 있다. 그래서 그냥 꾸준히만 해도 살아남는다."*
공통: 10개 올려보고 그만두는 사람이 99%.

### 6. 하나 만들어 여러 곳에 (원소스 멀티플랫폼)
박준휘·링밥 둘 다 **영상 1개 → 5군데**. 돈농부는 **페이스북에서만 10억**.
*"유튜브만, 인스타만 보면 시장이 너무 작다."*

# 5부 · 업그레이드해서 우리만 할 수 있는 것

그들이 **수작업으로 하는 것을 우리는 코드로** 한다. 이게 우리 차별점이다.

### A. 소재 발굴 자동화 (그들은 손으로 한다)
- 링밥은 인스타 계정 2,000개를 수집하는 프로그램을 **직접 만들어** 30만 대본을 분석했다
- 개발남 노씨는 **유튜브 파인더**를 만들어 구독자 대비 효율로 정렬한다
- **우리는 이미 트렌드 API가 있다.** 여기에 "효율 = 조회수 ÷ 구독자" 정렬과
  "조회수 추이가 평평해진 영상"(재각색 적기) 판정을 붙이면 그들 도구를 넘어선다

### B. 후킹 엔진 × 성과 장부 사이클 (아무도 안 한다)
- 그들은 "터진 것을 가져온다"까지다. **왜 터졌는지 수치화하지 않는다**
- 우리는 15개 장치별 배율을 우리 계정 데이터로 갱신한다 → **돌수록 똑똑해진다**

### C. 저작권 안전 파이프라인
- 크리에이티브 커먼즈 필터 + "최상단 업체 댓글" 판별 + 중복도 회피를 **코드 규칙으로** 박는다
- 그들은 사람이 눈으로 판단한다 → 우리는 자동 검사

### D. 원소스 6플랫폼 자동 배포
- 그들은 손으로 5군데 올린다
- 우리는 유튜브·인스타·스레드·틱톡·**네이버 클립**·카카오 숏폼으로 자동 배포

# 6부 · 실행 계획

## 1단계 (이번 주) — 이미 있는 것을 돈으로 연결
1. **쿠팡 파트너스 가입 + 인포크링크 세팅** ← 이게 없으면 쇼핑 쇼츠 수익이 0
2. goldenwoo.ai **프로페셔널 전환 완료 + 메타 API 연동** (진행 중)
3. 스레드 글에 **대가성 문구 + 쿠팡 링크** 붙이기 (스레드 자동화는 이미 돌고 있다)
4. `shortsStudio`로 첫 쇼핑 쇼츠 10편 생성 → 유튜브·인스타·스레드 동시 업로드

## 2단계 (2주차) — 소재 발굴 자동화
5. 트렌드 API에 **효율 정렬(조회수÷구독자)** + **재각색 적기 판정** 추가
6. 아이템스카우트/데이터랩 연동 → **쿠팡 재고 확인 자동화** (없는 상품 영상 만드는 낭비 차단)
7. 저작권 안전 검사기 (CC 필터 + 업체 댓글 판별)

## 3단계 (1개월) — 채널 확장
8. **AI 롱폼 경제 채널** 개설 (RPM 최고). 개발남 노씨 파이프라인 + 우리 후킹 엔진
9. **일본 쇼츠** — 기존 쇼츠에 번역 레이어만 추가 (수익 2배)
10. **AI 플레이리스트** 채널 1개 (주 1회, 10분 투자, 연금형)

## 4단계 (3개월) — 데이터 우위 확보
11. 성과 장부에 전 채널 연결 → **우리만의 배율표** 완성
12. 배율표로 소재·시간대·플랫폼 비중 재편성

## 안 할 것
- **이베이 리셀** — 실물 재고·배송. 우리 무재고 원칙과 안 맞음
- **양산형 쇼츠 대량 채널** — 저작권·삭제 리스크 대비 이득이 작음
- **강의 판매** — 우리는 콘텐츠로 번다
