## 1. 출해 KOL 플랫폼 — 등록 대상 5곳

중국 브랜드가 해외 유튜버를 찾을 때 실제로 검색하는 곳입니다. **크리에이터 등록은 전부 무료**입니다.
가입은 본인 인증이 필요해 제가 대신 못 합니다. 대신 **§2의 프로필 문구를 그대로 붙여넣으시면** 됩니다.

| 순위 | 플랫폼 | 성격 | 가입 |
|---|---|---|---|
| **1** | **NoxInfluencer (Nox聚星)** | 중국 최초 해외 인플루언서 마케팅 SaaS. 해외 KOL 1,800만 DB / 등록 활성 인플루언서 20만. 브랜드가 캠페인을 올리면 크리에이터가 지원 | noxinfluencer.com → Creator 등록 |
| **2** | **SocialBook** | 글로벌 KOL 1,600만. 유튜브·틱톡·인스타 커버. 중국 셀러가 많이 씀 | socialbook.io |
| **3** | **impact.com** | 2008년 설립, 글로벌 파트너십 마케팅 플랫폼. 대형 브랜드 캠페인이 많음 | impact.com → Creator |
| **4** | **WotoHub** | 2026년 4대 해외 네트워크 마케팅 플랫폼에 함께 꼽힘 | wotohub.com |
| 참고 | **Social Blade** | 가입 없이 채널 통계가 공개되는 곳. 브랜드가 검증용으로 봅니다 — **여기 우리 채널 데이터가 이미 노출되고 있습니다** | 가입 불필요 |

## 3. 브랜드 직접 제안 메일 — 초안

**받는 주소는 제가 지어내지 않았습니다.** 아래 순서로 찾으시는 게 정확합니다.
1. **지난 캠페인 담당자 메일이 최고입니다** — 지메일에서 `DJI`, `Bambu`, `Dreame`, `Temu` 검색

## 4. 협찬비 + 쿠팡 수수료 이중 수취

DJI · Dreame · Bambu Lab · Haier 전부 쿠팡에서 팝니다. 협찬비를 받으면서 설명란에
파트너스 링크를 넣으면 **판매 수수료가 별도로** 들어옵니다.
**클릭 후 24시간 내 산 아무 물건**이 다 잡히므로, 그 제품이 안 팔려도 수익이 납니다.

### 설명란 템플릿 (그대로 복사)

```
──────────────────────────────
🎬 이 영상은 [브랜드]로부터 제품과 소정의 원고료를 지원받아 제작되었습니다.

🛒 영상 속 제품 보러가기
[쿠팡 파트너스 링크]

이 포스팅은 쿠팡 파트너스 활동의 일환으로,
이에 따른 일정액의 수수료를 제공받습니다.
──────────────────────────────
```

**주의 3가지**
1. **대가성 문구를 맨 위에.** 공정위 지침입니다. 브랜드가 빼달라고 해도 거절하세요.
2. **쿠팡 문구는 별도로 또 넣어야 합니다.** 협찬 표기와 제휴 표기는 다른 규정입니다. 둘 다 씁니다.
3. **subId에 콘텐츠 ID를 심으세요.** 정산 리포트에 그대로 찍혀 어느 영상이 얼마 벌었는지 나옵니다.
   ```
   node scripts/affiliate.js add <콘텐츠ID> "<쿠팡링크>" "<제품명>" youtube
   node scripts/affiliate.js block <콘텐츠ID>
   ```
   → **쿠팡 파트너스 가입이 아직 병목입니다.** `.env`의 `COUPANG_ACCESS_KEY` / `COUPANG_SECRET_KEY` 비어 있습니다.

## 5. 우리 CPV 역산 — 단가를 올릴 근거 만들기

협찬 단가의 표준 산식은 **평균 조회수 × CPV**입니다. 구독자 수가 아니라 조회수 기준이
우리에게 유리합니다(40.2만 구독 대비 협찬 평균 17만 = 효율 0.42).

```
우리 CPV = 지난 캠페인에서 받은 금액 ÷ 170,086
```

| 받은 금액 | 우리 CPV | 판단 |
|---|---|---|
| 150만원 | 8.8원 | 낮습니다. 인상 근거 충분 |
| 300만원 | 17.6원 | 보통 |
| 500만원 | 29.4원 | 적정 |
| 850만원 | 50원 | 높은 편 — 유지 협상 |

**지금까지 실제로 받으신 금액을 알려주시면** 위 표에 대입해서, 인상 요구를 할 근거가
있는지 없는지 숫자로 정리해 드리겠습니다. 시장가는 제가 단정할 수 없지만, **우리 CPV가
얼마인지는 계산할 수 있고 그게 협상 테이블에서 쓰는 숫자**입니다.

**패키지 인상 논리**: 지금 롱폼+쇼츠를 같은 날 내고 계신데(7/24 뱀부랩, 4/1 DJI)
이게 1건 단가로 계산되고 있다면, 합산 조회수 기준으로 다시 계산해야 합니다.
DJI 캠페인은 롱폼 346,081 + 쇼츠 288,948 = **635,029회**였습니다.

## 6. 샤오홍슈 · 빌리빌리 — 확인된 요건

중국 내수 노출이 붙으면 "한국 검증 + 중국 현지 홍보"가 되어 단가 근거가 하나 더 생깁니다.
**가입은 본인 인증이 필요해 제가 대신 못 합니다.** 요건만 확인해 드립니다.

### 小红书 (샤오홍슈 / RedNote)
- **비대륙 거주자 실명인증**(非大陆居民实名认证) 경로가 별도로 있습니다 — 설정에서 접근
- 외국인도 **전문계정(专业号)** 신청 가능
- ⚠️ **라이브 방송 권한은 중국 대륙 신분증이 필요합니다.** 영상 게시는 됩니다
- 해외 휴대폰 번호로 가입 시 인증번호 수신이 막히는 사례가 있습니다

### 哔哩哔哩 (빌리빌리)
- **2026년 8월 글로벌 앱 출시** — 해외 사용자 대상 신분인증 요건이 완화됐습니다. 타이밍이 좋습니다
- 게시 권한을 얻으려면 **"转正测试"(회원 전환 퀴즈)** 를 통과해야 합니다
- 신분 서류는 외국인 영주권 또는 **타국 발행 신분증**이 인정됩니다
- 국제 전화번호 지원

**추천 순서**: 샤오홍슈 먼저. 육아·가전 카테고리가 샤오홍슈의 주력이고 브랜드 담당자들이
실제로 여기서 레퍼런스를 확인합니다. 빌리빌리는 롱폼이라 편집 부담이 더 큽니다.

**올릴 것**: 기존 영상에 중문 자막만 붙여 재편집. 새로 찍을 필요 없습니다.
