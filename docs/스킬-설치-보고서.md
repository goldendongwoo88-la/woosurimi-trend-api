## 1. 설치 완료: graphify

- 요청 링크: `lazyowen.com/guides/graphify`
- 실제 출처: https://github.com/wfsh2026/skill-graphify (MIT, 한국어 README 제공)
- 설치 위치: `.claude/skills/graphify/SKILL.md`
- 고정 커밋: `a104a0d9fc782f1485ad35cadd14aa6e4cf8a0e8`

GitHub 원본을 그대로 가져왔기 때문에 내용이 검증된 진짜 스킬입니다.

### 무엇을 하는 스킬인가

폴더 하나를 통째로 읽어서 **지식 그래프**로 만들어 줍니다.
코드, PDF, 마크다운, 스크린샷, 다이어그램, 손글씨 화이트보드 사진까지 처리합니다.

동작은 2패스입니다.

1. **AST 패스** — 코드 파일에서 클래스/함수/import/콜그래프를 LLM 없이 결정론적으로 추출
   (tree-sitter, 20개 언어: Python, JS, TS, Go, Rust, Java, C, C++, Ruby, C#, Kotlin,
   Scala, PHP, Swift, Lua, Zig, PowerShell, Elixir, Objective-C, Julia)
2. **서브에이전트 패스** — 문서·논문·이미지를 병렬로 읽어 개념과 관계를 추출

결과를 NetworkX 그래프로 합치고 Leiden 커뮤니티 탐지로 클러스터링합니다.
**임베딩·벡터DB를 쓰지 않습니다.** 그래프 구조 자체가 유사도 신호입니다.

모든 관계(엣지)에 출처 태그가 붙는 것이 이 스킬의 핵심입니다.

- `EXTRACTED` — 원문에서 직접 발견
- `INFERRED` — 추론 (신뢰도 점수 포함)
- `AMBIGUOUS` — 검토 필요 표시

즉 **"찾은 것"과 "지어낸 것"이 구분됩니다.**

### 산출물

```
graphify-out/
├── graph.html       인터랙티브 그래프 (노드 클릭·검색·커뮤니티 필터)
├── GRAPH_REPORT.md  허브 노드, 의외의 연결, 추천 질문
├── graph.json       영속 그래프 (몇 주 뒤에도 재읽기 없이 쿼리)
└── cache/           SHA256 캐시 (재실행 시 변경분만 처리)
```

### 사전 요구사항

Python 3.10+ 가 필요합니다. 파이썬 패키지는 스킬이 최초 실행 시 자동 설치하지만,
수동으로 하려면:

```bash
pip install graphifyy
```

> 패키지명이 `graphifyy`(y 두 개)인 이유는 PyPI에서 `graphify` 이름을 되찾는 중이기
> 때문입니다. CLI와 스킬 명령어는 그대로 `graphify` 입니다.

### 활용법

```bash
/graphify                      # 현재 폴더 전체 분석
/graphify ./scripts            # 특정 경로만
/graphify . --mode deep        # 정밀 추출 (INFERRED 엣지 더 풍부하게)
/graphify . --update           # 증분 — 새로 바뀐 파일만 재추출
/graphify . --watch            # 폴더 감시, 코드 변경 시 자동 재빌드 (LLM 미사용)
```

질의:

```bash
/graphify query "썸네일 생성은 어디서 처리되나"
/graphify query "홈판 로직 흐름" --budget 1500   # 답변을 N토큰으로 제한
/graphify path "server.js" "네이버API"            # 두 개념 사이 최단 경로
/graphify explain "homefeed-deep-v2"              # 특정 노드를 평이한 말로 설명
```

내보내기:

```bash
/graphify . --svg        # graph.svg (Notion·GitHub에 임베드됨)
/graphify . --graphml    # Gephi, yEd 용
/graphify . --neo4j      # cypher.txt 생성
/graphify . --wiki       # 에이전트가 크롤링 가능한 위키 생성
/graphify . --mcp        # MCP stdio 서버로 띄워서 다른 에이전트가 접근
```

외부 자료 수집 (Karpathy 의 `/raw` 폴더 워크플로우):

```bash
/graphify add <url>                      # URL 가져와 ./raw 에 저장 후 그래프 갱신
/graphify add <url> --author "이름"
```

제외 설정은 `.graphifyignore` 에 `.gitignore` 와 같은 문법으로 작성합니다.

```
node_modules/
public/
data/
*.generated.js
```

### 이 저장소에서 쓸 만한 곳

이 repo 는 `scripts/` 아래 스크립트가 60개 넘고 `README.md` 가 5만 자가 넘습니다.
전체 구조가 머리에 안 들어오는 상태라면 `/graphify .` 한 번 돌려 놓고
`graph.json` 을 세션 간에 재사용하는 쪽이 매번 파일을 grep 하는 것보다
토큰이 훨씬 적게 듭니다. (원문 직접 읽기 대비 쿼리당 71.5배 절감이 공식 수치입니다.)

## 2. 저장소 특정 완료 / 사용자 실행 필요: ECC (Everything Claude Code)

- 요청 링크: `app.notion.com/p/Everything-Claude-Code-ECC-...` (Notion — 차단되어 원문 못 읽음)
- 실제 출처: https://github.com/affaan-m/everything-claude-code (MIT, 한국어 README 있음)

Notion 원문은 못 읽었지만, ECC 는 공개 GitHub 프로젝트이고 README 를 직접 확인했으므로
정체는 확실합니다. Anthropic 해커톤 우승작이고 에이전트 하네스용 성능 최적화 시스템입니다.
에이전트 16개, 스킬 65개, 커맨드 40개가 들어 있습니다.

### 왜 이 repo 에 파일로 설치하지 않았는가

ECC 는 **Claude Code 플러그인**이라 `/plugin` 명령으로 설치하는 것이 정규 경로입니다.
그리고 ECC 스킬 65개를 이 repo 의 `.claude/skills/` 에 그냥 복사하면,
지금 있는 한국어 블로그 스킬 30여 개가 범용 개발 스킬에 묻혀서
**스킬 자동 선택 정확도가 떨어집니다.** 그래서 일부러 복사하지 않았습니다.

### 설치 방법 (Claude Code 세션에서 직접 실행)

```bash
# 1단계 — 마켓플레이스 추가 후 플러그인 설치
/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
```

```bash
# 2단계 — 룰 설치 (필수, 플러그인이 자동 배포 못 함)
git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code
./install.sh typescript          # python, golang 도 가능 / 여러 개 동시 지정 가능
```

```bash
# 3단계 — 사용
/ecc:plan "네이버 홈판 스코어링 로직 추가"
/plugin list ecc@ecc             # 사용 가능한 커맨드 확인
```

플러그인으로 설치하면 커맨드가 `/ecc:plan` 처럼 네임스페이스가 붙고,
수동 복사로 설치하면 `/plan` 처럼 짧은 형태가 됩니다.

## 3. 분석 불가 — 원문 접근 차단 (19개)

### 차단 사유

이 세션의 아웃바운드 네트워크는 조직 egress 정책으로 막혀 있습니다.
확인 결과 **GitHub(github.com, raw.githubusercontent.com)과 패키지 레지스트리
(npm, PyPI)만 통과**하고, 나머지는 프록시가 CONNECT 단계에서 403 으로 끊습니다.

실제 확인한 차단 도메인:

| 도메인 | 결과 |
|---|---|
| `lazyowen.com` | 403 (CONNECT tunnel failed) |
| `*.notion.site` | 403 |
| `app.notion.com` / `notion.so` | 403 |
| `skillsllm.com`, `claudeskills.info` | 차단 |
| `tokensave.dev`, `claudepluginhub.com` | 차단 |
| `news.hada.io`, `wikidocs.net` | 차단 |

Notion MCP 커넥터로도 시도했지만, 해당 커넥터는 **사용자 본인 워크스페이스**에만
인증되어 있어서 남의 공개 페이지는 404 로 나옵니다.

### 추측으로 만들지 않은 이유

`tokensave`, `prompt-master`, `agent-reach`, `Ruflo` 같은 이름만으로는
원본이 무엇인지 특정되지 않습니다. 검색으로 비슷한 이름의 도구가 여러 개 나오는데
(예: `tokensave` 만 해도 Rust crate, MCP 서버, Claude 플러그인이 각각 존재),
가이드가 그중 무엇을 다뤘는지 알 수 없습니다.
잘못 짚은 스킬을 설치하면 이름만 같고 동작이 다른 스킬이 `.claude/skills/` 에 남아
오히려 방해가 되므로 만들지 않았습니다.

### 해결 방법 (셋 중 하나)

1. **본문을 직접 붙여넣기** — 가장 확실합니다. 가이드 페이지 내용을 복사해 주시면
   그대로 분석해서 스킬로 만듭니다. SKILL.md 코드블록이 있으면 그것만 주셔도 됩니다.
2. **GitHub 저장소 주소를 알려주기** — 가이드가 공개 GitHub 스킬을 소개하는 글이라면
   그 repo 주소만 주시면 이 세션에서 바로 clone 해서 설치할 수 있습니다.
   (GitHub 는 이 세션에서 통과됩니다.)
3. **egress 정책이 느슨한 환경에서 재실행** — 환경 설정에서 네트워크 정책을 바꾸면
   `lazyowen.com` 과 Notion 을 직접 읽을 수 있습니다.
   참고: https://code.claude.com/docs/en/claude-code-on-the-web
