✅ 유튜브에서도 같은 결론이 실측으로 나왔습니다 — 14채널 41편 전수 조사에서 영상 설명란에 제휴 링크를 넣은 채널이 0곳이었습니다. 전부 고정댓글·프로필로 갑니다. 스레드에서 내린 판정이 플랫폼을 건너 재확인됐습니다.

  2. 첫 게시물에 외부링크 금지
  3. 게시 후 조회수가 붙으면 그때 댓글에 링크 추가
  4. 또는 프로필에 인포크링크 걸고 본문은 "프로필 확인"으로 유도
  5. PC와 모바일 동시 로그인 금지 (다중 기기·IP = 부정행위 감지)
  6. 게시 간격을 불규칙하게 (30분·1시간 같은 기계적 주기 금지)
  7. 공정위 고지문구 필수 — 누락 시 쿠팡 계정 자체가 박탈될 수 있음

3. 분야별 정리 — 10분야

A. 쇼핑쇼츠·제휴 (12편) — 이미 하고 있는 것, 새로 얻은 것만

새로 얻은 것 3가지

  1. 플랫폼 이원화: 인스타를 수익 채널, 유튜브를 트래픽 채널로 나눕니다. 유튜브 단독 올인과 인스타 전환 사이의 절충안이고, 유튜브 정지 리스크를 분산합니다.
  2. 유튜브 정지 3대 판별 기준: 허위 콘텐츠 / 중복도 / 저작권. 그중 실질 트리거는 중복도입니다 — 같은 바이럴 소스를 여러 채널이 재사용하면 걸립니다. 저작권보다 중복도가 먼저 잡습니다.
  3. 소스 2~3초씩 섞기: 한 소스를 길게 쓰지 않고 여러 소스를 2~3초 단위로 섞어야 중복도를 피합니다.

대본 규칙 (기존 후기체 규칙과 일치, 재확인): 초반 2초 후킹 → 문제제기·해결 → CTA. AI 목소리보다 본인 목소리(또는 자연스러운 클로닝)가 전환에 유리.

⚠️ 안 따라 할 것: 중국 도우인·샤오홍슈 영상 다운로드 후 재편집. 6편 중 4편이 이 방식인데, 한 명은 실제로 채널 정지를 겪었고 나머지는 "아직 안 걸렸다"입니다. 기존 결정(project_shopping_shorts_playbook) 유지합니다.

  • 노트북LM을 사실 조사에 씁니다. 제미나이·챗GPT는 할루시네이션 위험이 있어 백과사전·조선왕조실록 같은 공신력 사이트만 넣고 조사시킵니다. 3편이 같은 이유로 같은 도구를 씁니다. → 우리 경제·역사 롱폼에 바로 적용됩니다.
  • 한 채널에 여러 주제를 섞으면 죽습니다("짬뽕"). 채널당 주제 1개.
  • 레퍼런스 그대로 따라 하면 그 카테고리 전체가 죽습니다 — 파생 창작만.
  • 수익창출까지: 2개월~7개월. 그 사이 4개월간 하루 1달러 정체기가 정상입니다(비니파).

니치 후보 목록 (영상들이 언급한 것 전부): 한국사·조선왕조 / 마음철학·명언 / 시니어 생활정보(기초연금) / 경제 일반(관세·환율·금값) / 경제 "몰락" 시리즈 / 건강·노후 서사 / 일본향 로컬라이즈 경제·건강

D. AI 영상툴 (14편) — 로컬 무료로 어디까지 되는가

§1-④에 라이선스 판정이 있습니다. 결론: LTX 2.5만 새로 채택하고, 나머지는 기존 Wan 2.2·Z-Image 유지.

캐릭터 일관성 — 6가지 방법이 나왔고, 우리에게 맞는 건 2개

  1. 캐릭터 시트를 3패널로 줄입니다 (정면·후면·얼굴 클로즈업). 앵글·소품·컬러코드를 다 넣으면 오히려 도플갱어가 생깁니다. 정보량을 줄이는 게 정답이라는 게 반직관적이라 값어치가 있습니다.
  2. 파일명으로 고정: 고정 캐릭터를 영어 파일명(golden.png·surimi.png)으로 통일해 프롬프트 생성부터 영상 자동화까지 같은 이름으로 매칭. → 우리 _shared/card-news 구조에 그대로 얹힙니다.

캡컷·브루 자동화의 정체 — 4편이 다뤘는데, 생성 자동화가 아니라 배치 자동화입니다. 이미지·영상·TTS·자막(SRT)을 미리 다 만들어 놔야 하고, 그걸 타임라인에 순서대로 넣어주는 역할만 합니다. 자막 크기 보정과 빈칸 채우기는 여전히 수동입니다.

→ 우리는 이미 ComfyUI + Voicebox로 앞단을 갖고 있으므로, 배치 단계만 코드로 만들면 됩니다. 남의 앱을 살 이유가 없습니다.

E. 블로그·애드센스 (8편) — 절반이 강의 퍼널

바로 쓸 것

  • 애드센스 승인 공식(§2 표) — 카테고리 1개, 20개 글, 1,500~1,800자.
  • 키워드 발굴에 네이버 카페를 씁니다. 뉴스판·크리에이터 어드바이저는 공개 정보라 남들도 이미 봅니다. 내 주제 관련 카페 5~20개에 가입해 인기글에서 커뮤니티 전용 키워드를 뽑는 게 유일한 차별화 경로입니다. → 우리 keywordMiner.js에 씨앗 공급원으로 추가할 지점입니다.

모순 정리: 사진 개수가 "최소 1장"과 "15~20장"으로 갈리는데, 목적이 다릅니다 — 애드센스 승인은 적게, 네이버 상위노출은 많이. 우리 실측(사진 90자 간격)은 후자 기준이라 그대로 둡니다.

자동 발행: 2편이 "네이버 API가 막혀 임시저장까지만"이라 하고 1편이 예약발행까지 시연합니다. 우리는 임시저장 유지합니다(CLAUDE.md §2). 계정이 날아가면 복구가 안 됩니다.

F. 개발 자동화·클로드코드 (15편) — 지금 세팅을 바꿀 것

바로 적용할 설정 6가지

  1. CLAUDE.md는 150~200줄 상한. 상세는 별도 md로 빼고 CLAUDE.md엔 "이 상황이면 이 파일 봐라"는 라우터 문장만 둡니다. → 우리 CLAUDE.md는 이미 이 구조입니다(docs/작업지침-상세.md로 분리). 유지.
  2. 지시문이 안 지켜지면 훅으로 강제합니다. 문장을 더 세게 쓰는 건 효과가 없습니다(3편 공통). → 우리 feedback_bake_rules_into_tools와 같은 결론.
  3. MCP 서버는 전체 툴을 컨텍스트에 로드합니다. 기능 1개만 필요하면 API 엔드포인트를 직접 호출하는 게 토큰이 덜 듭니다.
  4. /context로 토큰 점유 확인 → 60% 도달 시 /compact, 작업 전환 시 /clear.
  5. git worktree로 여러 세션의 파일 충돌 방지. → 지금 세션 6개를 동시에 굴리고 있어 바로 값어치가 있습니다.
  6. settings.json에 위험 명령(rm, git push --force) 승인 필수 목록 설정.

모델 라우팅 — 전략·판단은 상위 모델, 코드는 중간, 파일 탐색 같은 잡무는 하이쿠. 3편이 독립적으로 같은 말을 했고, 우리 기존 방침(feedback_leader_not_worker)과 일치합니다. 이번 100편 분석 자체를 그 방식으로 돌렸습니다.

⚠️ 걸러낸 것: 실제 자금 AI 자동매매(규제·손실 위험 + 증권사 이벤트 결합 홍보) · "구글만 영상 분석이 된다"(근거 없음) · 모델별 벤치마크 비용표(특정 시점 스냅샷이라 이미 무효 가능).

G. 인스타·사진 (7편) — 보너스는 조건부, 인스타툰은 별개 사업

  • 인스타 보너스 조건: 18세 이상 + 한국 거주 + 3개월 조회수 100만. 조건 자체는 명확한데, 우리 기존 판단(부서별-수익화-보완분석: "보너스는 버리십시오")을 바꿀 만큼은 아닙니다. 3개월 100만 뷰가 선행 조건이라 보너스는 결과이지 전략이 아닙니다.
  • 인스타툰은 별개 사업입니다. 광고 단가 장당 15만원(10장 계약 150만원), 구독형 3,300원×구독자. 캐릭터 6종을 도장처럼 반복 사용하는 구조라 우리 AI 이미지 역량과 맞습니다. 다만 2편 다 강의 퍼널이라 수익 수치는 전부 [주장]입니다.
  • 게시물 과다 업로드는 스팸 판정 → 노출 감소.

H. 해외·역직구·일본 (5편) — 단가 1.5배는 사실로 보입니다

  • 일본 단가가 한국의 1.5배라는 건 2편이 독립적으로 말했고, 한 편은 화면 인증까지 있습니다(1,000회당 일본 15,000원 / 국내 8,300원).
  • 근거는 일본의 겸업 금지 문화로 크리에이터 공급이 적다는 것입니다. 구조적 설명이 있어서 신뢰도가 높습니다.
  • 단순 번역이 아니라 문화 치환이 필요합니다(태권도→가라테 식).
  • ⚠️ 5편 전부 플랫폼 수수료율·정산 주기를 한 번도 말하지 않았습니다. 매출 화면은 보여주면서 수수료는 안 밝힙니다. 역직구(Qoo10)를 검토한다면 이것부터 확인해야 합니다.
  • 역직구는 부피무게 계산 실수 시 배송비 폭탄이 핵심 함정입니다. 마진 10~20%인데 배송비가 6,000~8,000원입니다.

I. 음성·음악·TTS (4편) — 우리 것이 이미 낫습니다

  • 로컬 음성 서버(AGPL 3.0)가 97편 중 유일하게 라이선스를 설명한 사례입니다: 생성 음성의 상업적 이용 가능, 단 프로그램을 고쳐 웹서비스로 재배포하면 소스 공개 의무.
  • 우리는 이미 Voicebox 로컬 무료를 쓰고 있어 갈아탈 이유가 없습니다(reference_voice_tts_options). 다만 오픈AI 음성 API와 같은 주소 형식으로 붙이는 방식은 참고할 만합니다 — 기존 코드를 안 고치고 엔드포인트만 로컬로 돌리는 구조입니다.
  • Suno는 확인이 필요합니다. 2편 다 "저작권 걱정 없다"고 하면서 정작 Suno의 상업적 이용·유튜브 수익화 자격 조건은 한 번도 설명하지 않습니다. AI 플레이리스트 채널을 열려면 이것부터 확인해야 합니다.
  • 음원은 디스트로키드 유통으로 별도 수익이 붙는다는 언급이 있습니다(J1).

J. 기타 부업·온라인 사업 (16편) — 대부분 우리 조건에 안 맞습니다

우리가 못 하는 것과 이유: 카톡 공동구매(동네 직접 배송) · 과자 소분판매(물리 노동) · 패션 브랜드(생산·재고·매장) · 자판기(공간·차량) · 코스트코 리셀(사입·재고).

→ 재택·무자본·AI 자동화라는 우리 조건과 정면으로 안 맞습니다. 참고만 하고 넘어갑니다.

단 하나 값어치 있는 것 — 1인 SaaS 구조 (월 2천만원 [주장])

  • 학교 상담교사용 데스크탑 앱. Electron + SQLite, 클라우드 안 씀(보안 거부감 때문에 로컬 저장으로 피벗한 게 성공 요인).
  • 가격: 연 구독 3단 (30만 / 48만 / 96만원)
  • 고객 확보: 스레드 → 화상미팅 → 유저 인터뷰 20회+ → 로컬 버전 피벗 → 무통장입금으로 첫 결제 → 사업성 검증 후 PG 연결 → 교육청 문의로 B2G 신뢰 확산
  • 유지: 1인 개발, 브랜치·테스트·PR 생략, QA는 실사용자 버그리포트 + 24시간 응대
  • 우리에게 주는 것: 이건 우리 gw_webdev_2026(웹제작 판매)과 붙습니다. 결제 시스템(PG)을 먼저 붙이지 말고 무통장입금으로 첫 결제를 받아 사업성을 검증한 뒤 붙이는 순서가 실무적으로 값어집니다.

콘텐츠 구성 참고 2편 (수익화와 무관, 형식만): 둘 다 11~14분, 여러 소주제를 나열하지 않고 하나의 축을 끝까지 팝니다. 전개는 "근거 제시 → 화자 해석"의 2단 구조를 계속 반복합니다. → 우리 경제 롱폼 22~28분 규격에 참고.

4. 🔶 사장님 확인이 필요한 것 — 3건

계획을 크게 흔드는데 자막만으로는 확정할 수 없는 것들입니다.

① 유튜브 수익창출 자격 조건이 정말 완화됐는가 — 최우선

두 영상이 "완화"를 말하는데 기준 자체가 다르고 둘 다 화면 인증이 없습니다.

  • 부업의온도: 구독 1,000명 + 유효조회수 1,000만뷰 → "각각 거의 절반으로" [주장]
  • 부업사냥꾼사냥: 쇼핑태그 조건이 구독 1만 → 구독 500명 + 90일 쇼츠 300만뷰 [주장]

애초에 다른 제도일 가능성이 높습니다(수익창출 자격 vs 쇼핑 제품태그 자격).

왜 1순위인가: §1-①의 50배 스위치가 여기 걸려 있습니다. 조건이 정말 절반으로 낮아졌다면 채널 개설 계획 전체가 바뀝니다.

확인 방법: 유튜브 스튜디오 → 수익 창출 탭에서 현재 계정에 표시되는 실제 요건 확인.

② Suno의 상업적 이용·유튜브 수익화 자격

AI 플레이리스트 채널은 진입 장벽이 낮고 "연금형"으로 분류될 만한데, 2편 다 라이선스를 설명하지 않았습니다. 요금제별로 상업적 이용 권한이 다를 가능성이 높습니다.

→ 채널을 열기 전에 Suno 약관 원문 확인이 필요합니다. (우리 규칙: 모델·서비스 쓰기 전에 라이선스부터 연다)

③ 토스 쉐어링크 가입 여부

수수료 10%로 쿠팡(3%)의 3.3배입니다. 같은 노력에 3배면 우선순위가 바뀝니다.

→ 가입은 사장님 계정 작업이라 제가 못 합니다. project_shopping_shorts_playbook의 "🔶 결정 대기: 토스 가입"이 아직 열려 있습니다.
