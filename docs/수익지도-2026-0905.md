## 2. 준비는 끝났는데 안 붙은 23편

`docs/설명란-소급적용-시트-2026-0902.md` 에 링크까지 다 채워 둔 23편입니다.
오늘 다시 확인했습니다.

```
시트 대상 26편 중
  🟢 붙여넣기 끝    0편 ·         0 조회
  🔴 아직 안 함    26편 · 3,736,869 조회
```

링크 23개 전부 살아 있고, `subId=yt_<영상ID>` 가 영상 ID 와 정확히 맞습니다(23/23 검증).
설명 길이도 전부 상한 5,000자 안입니다 (가장 긴 것 2,959자).

**손으로 하면 영상당 2분 × 23편 = 46분이라 안 하신 것으로 봅니다. 그래서 명령 하나로 만들었습니다.**

```bash
powershell -ExecutionPolicy Bypass -File scripts\크롬-우수리미.ps1   # 크롬 띄우기 (한 번)
node scripts/설명란-붙이기.js                                        # 미리보기
node scripts/설명란-붙이기.js --한편 9iQmvX9u_LU                     # 한 편만 시험
node scripts/설명란-붙이기.js --진짜                                 # 23편 전부
```

- **기존 설명을 안 지웁니다.** 맨 앞에만 끼워넣습니다 (협찬 링크·해시태그 그대로)
- 설명칸을 **위치가 아니라 지금 들어 있는 글로 찾습니다** — 엉뚱한 칸을 안 건드립니다
- 이미 붙은 영상은 건너뜁니다 (여러 번 돌려도 안전)
- 끝나고 **유튜브에 다시 물어봐서** 실제로 들어갔는지 셉니다. 저장 버튼을 눌렀는지가 아니라

**막힌 곳**: 전용 크롬 프로필 5개 중 우수리미부부 계정이 없습니다.
`youtube_latedesk` 는 느지막한 책상, `youtube_golden_econ` 은 부부 경제 연구소입니다.
**로그인은 제가 못 합니다.** 사장님이 1분만 로그인해 주시면 나머지는 자동입니다.
