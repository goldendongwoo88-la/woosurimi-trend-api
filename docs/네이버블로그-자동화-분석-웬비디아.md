# 네이버 블로그 자동화 — 외부 사례 분석과 우리 적용

출처: 프리미엄콘텐츠 「[바이브코딩⑫] 네이버 블로그 완전 자동화 발행하기 +프롬프트 팁」(웬비디아, 2026-07-17)
분석일: 2026-09-01 · **유료 콘텐츠라 원문은 옮기지 않는다. 방법과 시사점만 정리한다.**

---

## 1. 제목과 실제가 다르다 — 이게 제일 중요하다

제목은 "완전 자동화 발행"이지만, 저자가 실제로 만든 규칙 12번은 이것이다:

> **게시글은 자동 발행하지 않고 모두 임시저장한다.**

즉 **소재조사 → 원고 → 에디터 입력 → 임시저장**까지가 자동이고, **발행 버튼은 사람이 누른다.**
우리가 그동안 "임시저장까지만" 해온 판단이 업계 실사례와 같다. 자동 발행으로 밀어붙일 이유가 없다.

## 2. 저자의 구조

```
topics   RSS 소재 수집·선정
capture  yt-dlp + ffmpeg 로 영상 프레임 추출
writer   claude -p 호출 + 원고 검증
editor   스마트에디터 ONE 자동화   ← Playwright
state    posted.json 중복 방지
```

- **Playwright + Chrome for Testing**(회색 창)로 브라우저를 조작한다.
- **로그인은 사람이 딱 한 번** 직접 한다. 계정 비번을 프로그램에 저장하지 않는다.
  (저자 표현: 요즘 AI 에이전트는 아이디·비번을 알려줘도 .env에 저장을 잘 안 해준다)
- 프로필 폴더를 재사용해서 세션을 유지한다.
- 윈도우 스케줄러로 하루 3개. **PC를 켜놔야 돌아간다.**

## 3. 우리가 이미 가진 것 / 없는 것

| 저자 구성요소 | 우리 상태 |
|---|---|
| topics (소재 수집) | 있음 — 편집국 + 트렌드 API + agent-reach |
| writer (원고) | 있음 — 블로그 편집국(8485) |
| **editor (에디터 입력·서식)** | **있음 — 블로그바 확장이 대신한다** |
| state (중복 방지) | 있음 — 발행큐 |
| capture (영상 프레임) | 없음 (우리는 사장님 실사진 사용 원칙) |
| **임시저장 자동화** | **없음 ← 유일한 진짜 공백** |

**중요:** 저자는 Playwright로 브라우저를 밖에서 조종한다. 우리는 **확장 프로그램이 브라우저 안에서** 같은 일을 한다.
우리 방식이 더 안전하다 — 비번을 안 다루고, 사장님이 이미 로그인한 세션 위에서만 움직인다.
따라서 Playwright를 새로 들일 이유는 **임시저장 클릭 하나** 때문뿐이다. 그건 확장에 붙이는 게 맞다.

## 4. 프롬프트 팁 — 여기가 진짜 자산이다

### 4-1. 네이티브 우선, 풀백 금지
- **네이티브**: 처음부터 그렇게 쓰게 지침에 넣는다
- **풀백**: 다 쓴 뒤에 고친다
→ 종결어미, 문체, 줄바꿈은 **전부 네이티브로.** 나중에 치환하면 글이 기계 같아진다.

### 4-2. 종결어미 다양화 (강제 치환 금지)
`입니다 / 습니다 / 이죠 / 하죠 / ~까요? / 됩니다 / 인데요 / 겠죠 / 습니까 / ~데요`
"단, 종결어미를 강제하여 풀백 방식으로 수정하지 말고 자연스러운 네이티브가 되도록 **글쓰기 지침 프롬프트에 반영**하자. 글의 온도 조절이 필요함."

### 4-3. 인용구 탈출 규칙 ← 우리가 오늘 똑같이 당한 문제
저자도 AI가 인용구에 들어간 뒤 못 빠져나와 **모든 글이 인용구에 들어가는** 사고를 겪었다.
저자의 해법이 정확하다:

> "인용구 뒤에 다시 본문을 적을 때에는 반드시 밑줄·볼드·기울이기 등을 **해제하고 15포인트에서 다시 시작**해야 함. 이건 **스크립트 작성 규칙으로 넣어야 함**"

핵심: **AI 판단에 맡기지 말고 코드 규칙으로 박아라.** 우리 원칙(코드가 규칙을 정하고 AI는 창작만)과 같다.

### 4-4. 무한루프 차단
> "안 되는 거 있으면 무한반복하지 말고 나한테 물어봐라. 알려줄테니까."

AI는 모르면 사람에게 묻지 않고 혼자 3~4시간을 태운다. 토큰이 그렇게 녹는다.

### 4-5. 표 3×3 함정
네이버 에디터 표는 기본 3×3이다. AI가 3×2를 원하면 열을 지워야 하는데 이걸 정말 못 한다.
정답: **첫 셀 클릭 → Shift+방향키로 영역 지정 → 뜨는 팝업에서 선택.**

### 4-6. 스티어링 프롬프팅
작업 중간에 프롬프트를 대충 쓰고 **ESC**를 눌러 방향을 튼다. 처음부터 다시 시키지 않는다.

### 4-7. 모델
저자는 **Fable 5**가 이 작업에서 제일 낫다고 본다 (opus 4.8 / gpt-5.6 sol보다). 추론 모드를 올릴수록 에디터를 잘 배운다.
