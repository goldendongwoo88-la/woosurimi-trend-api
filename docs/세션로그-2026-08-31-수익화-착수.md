| 파일 | 제목 | 분량 |
|---|---|---|
| `ebook-draft.json` | **2026년 네이버 블로그 상위노출** — 연관검색어 사라진 시대, 바뀐 로직에 맞춰 다시 쓰는 법 | 서문 1,464자 + **8장 18,583자** = 약 20,047자 |

**데이터 구조** (스크립트 작성 시 참고):
```
{ book: { title, subtitle, promise, chapters:[{title, points:[]}] },
  parts: { intro: "마크다운 문자열", chapters: ["# 1장. ...\n\n본문...", ...] } }
```
- `parts.chapters`는 **각 장의 전체 본문 문자열 배열** (제목 `# N장. ...`이 첫 줄에 포함됨)
- `book.chapters[].points`는 목차용 소주제. **`body` 필드는 없음** → 북 팩토리 포맷
  (`chapters:[{title, body}]`)으로 **변환이 필요**함

### 작업 중 발견해서 고친 것 (다음 세션이 또 밟지 않도록)

1. **`buildSections`의 조용한 누락** — `compare`/`specs`를 **배열**로 넘기면 객체(`{point,…}` / `{k,v}`)로만
   읽습니다. 사람이 쓰기 편한 문자열 배열(`"항목 | 우리 | 일반"`, `"용량: 500ml"`)을 그대로 넣으면
   **행이 전부 걸러져 비교표·스펙표 섹션이 통째로 사라지는데 에러가 안 납니다.**
   → `render-detail-page.mjs`의 `normalizeMemo()`가 미리 풀어 줍니다.
2. **한글 폰트에 없는 기호는 두부(□)로 렌더** — `℃ ✓ ※ ㎡` 등. NotoSansKR-Bold에 글리프가 없습니다.
   → `sanitize()`로 대체(℃→°C) 또는 제거하고, 체크표시는 SVG 선으로 직접 그립니다.
3. **fontkit은 CJS** — `.mjs`에서 `import fontkit from "fontkit"`이 실패합니다.
   → `createRequire(import.meta.url)("fontkit")`.
4. **preview_start가 `node`를 못 찾음** — PATH에 없어서. `.claude/launch.json`에 포터블 노드 절대경로를 쓴
   `detail-portable` 항목을 추가했습니다(작업 디렉터리 기준은 `my-project`, 그래서 경로가 `..\golden-detail-factory`).
