## 1. 코드로 적용한 것 (4건)

### ① AI티 검사기 — `golden-blog-floor/src/humanTouch.js` ✅

출처: **휴먼 TOUCH 프롬프트**(갓생맘)

프롬프트에 규칙을 얹지 않고 **코드로** 만들었습니다. 위에 적은 207개 문제 때문입니다.
그리고 이 일은 판단이 아니라 세기입니다 — 접속사로 시작하는 문장, 같은 어미 3연속,
60자 넘는 문장은 규칙이지 창작이 아닙니다. **0원**이고 사장님 원칙("코드가 규칙, AI는 창작")과 맞습니다.

검사 항목 6가지: 접속사 시작 / 어미 3연속 / 긴 문장 / 강조 부사 과다 / 번역투 / 경험 넣을 자리

⚠️ **고치지 않고 찾아서 알려줍니다.** 자동으로 문장을 바꾸면 사실이 틀어집니다.
경험도 자리만 표시하고 **지어내지 않습니다.**

실측: 최근 원고 4편 **86~93점**. (돌면서 오탐 하나 잡음 — URL·해시태그 줄이 "긴 문장"으로 잡혔습니다)

연결: 배치 생산 시 자동 검사, `POST /api/humantouch`

### ② H-V-P-R-C 릴스 구조 — `src/shortsAgent.js` ✅

출처: **REELS_SCRIPT**(godsengmom prompt drop)

훅(0~3초) → 가치 → 증명 → 결과 → 안내를 **초 단위 구성표**로 자동 생성합니다.
우리 파인더 실측과도 정확히 맞습니다 — 상위 22편이 **전부 문제 장면으로 열었고**,
정리된 모습으로 시작한 영상은 상위권에 없었습니다.

### ③ 훅 7유형 + 심리 근거 — `src/shortsAgent.js` ✅

출처: **HOOK_3SEC**

문제 지적 / 손실 회피 / 숫자 충격 / 반전 / 권위 / 금지 / 즉시성.
"어떤 심리를 건드리는지"를 같이 붙였습니다 — 고를 때 근거가 됩니다.

### ④ 한국어 조사 처리 ✅

"접시선반**를** 꺼내며", "네트망**로** 공간 두 배" 같은 문구가 나오고 있었습니다.
받침을 보고 을/를, 로/으로를 고릅니다. 사소해 보이지만 **광고가 아마추어로 보이는 지점**입니다.

## 2. 설치한 것 (2건)

### Parabolic (영상 다운로드) ✅
바탕화면 **"Parabolic 영상받기"**. 품고 있던 yt-dlp가 2026.03이라 **최신판(2026.08)으로 교체**했습니다 —
안 그러면 막히는 사이트가 생깁니다.

### Scrapling (웹 수집) ✅
`pip install scrapling[fetchers]` 완료.
쿠팡에 시험했더니 **200은 나오지만 내용이 봇 차단 화면**(Akamai)이었습니다.
Scrapling에는 이 차단을 뚫는 기능이 있지만 **쓰지 않았습니다** — 사이트가 일부러 세운
접근 차단을 우회하는 일이고, 실익도 없습니다(제휴 수수료를 받으려면 어차피 공식 API가 필요합니다).
**봇 방어가 없는 사이트 수집에는 유용**하니 남겨뒀습니다.
