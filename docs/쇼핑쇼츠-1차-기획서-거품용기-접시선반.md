## 0. 왜 이 두 개인가

파인더로 '다이소 추천템'·'주방 살림템' 쇼츠를 훑어 **효율(조회수÷구독자)**이 터진 영상에서 제품만 뽑았다.

| 제품 | 효율 | 조회수 | 그 채널 구독자 | 길이 |
|---|---|---|---|---|
| **거품용기** | **2,015** | 186만 | **925명** | 29초 |
| **접시선반** | 445 | 45만 | 1,020명 | 42초 |

구독자 900명대가 186만을 냈다. **채널이 아니라 물건이 터진 것**이고, 구독자 없는 우리가 노릴 자리다.

⚠️ **남의 영상은 안 가져온다.** 저작권 침해이고 유튜브 재사용 콘텐츠 정책에 걸려 수익화가 거절된다.
가져오는 건 **제품 신호와 형식(제목·길이·구성)**뿐이다. 형식은 저작권 대상이 아니다.

## 1. 공통 공식 (22편 실측)

## 1-2. 확정한 쿠팡 상품 (2026-09-01)

쿠팡은 서버·브라우저 모두 접근이 막혀 있어 **사장님 화면 캡처를 보고 골랐다.**
상품명은 캡처에서 읽은 것이라 정확하지 않을 수 있다. **가격·할인율·로켓 표시·사진 모양**으로 찾을 것.

| 제품 | 고른 것 | 가격 | 왜 |
|---|---|---|---|
| 거품용기 | 코넷 버블폼 용기 **150ml, 투명, 2개** | 4,390원 (36%↓) 🚀로켓 | 30ml는 여행용이라 "반년 쓴다" 메시지와 안 맞음. 투명이라 거품 차오르는 게 화면에 보임 |
| 접시선반 | 고형 키친 접시 정대 **8칸, 실버** | 6,490원 (49%↓) 🚀로켓 | 칸이 많아 화면이 참. 와이어형이라 냄비뚜껑·도마가 실제로 들어감 |

**백업**
- 거품용기: 리베이라 버블폼 100ml 2개 3,000원(88%↓) — 할인율이 세서 가성비 훅에 유리. 로켓 여부 확인 필요
- 접시선반: 월하우스 스테인리스 접시꽂이 5,190원 🚀로켓 — "녹 안 슨다" 각도 추가 가능

⚠️ 리뷰 수는 확인 못 했다. 100개 미만이면 백업으로 바꿀 것.

## 2. 거품용기 — "가격 훅 + 조합"

### 근거
상위 3편이 전부 **단품이 아니라 조합**이었고, 전부 **가격을 제목에 박았다**.

- 효율 2,015 · 186만 · 29초 — "다이소 화장품 조합 채비공간 토너 + 퍼프 + 거품용기"
- 효율 1,341 · 26만 · 26초 — "**단돈 6천원**에 인생 미스트 완성"
- 효율 1,333 · 23만 · 34초 — "올영맹신자도 결국 다이소 갔다.. **6천원** 가성비 꿀조합"

→ **거품용기 하나만 팔면 안 된다. "○천원 조합"으로 묶어야 터진다.**

### 제목 후보 10개
1. 다이소 3천원 거품용기, 세안이 이렇게 바뀝니다
2. 단돈 5천원에 거품 세안 완성하는 조합
3. 다이소에서 보이면 무조건 담는 거품용기
4. 올리브영 안 가도 되는 다이소 5천원 조합
5. 거품용기 하나로 클렌저 반년 쓰는 법
6. 다이소 거품용기, 이걸 왜 이제 알았을까
7. 세안 거품 3초 만에 만드는 3천원짜리
8. 다이소 뷰티 신상 중에 이거 하나는 사세요
9. 클렌저 값 절반으로 줄이는 다이소 꿀템
10. 5천원으로 끝내는 아침 세안 루틴 3가지

> 1·2·4·7·10번이 공식에 가장 가깝다(숫자 + 27자 내외 + 단정형).

### 33초 구성표

| 초 | 화면 | 자막(화면에 박기) | 소리 |
|---|---|---|---|
| 0.0~2.5 | 손이 거품용기 펌프를 누르고 거품이 솟는 클로즈업 | **거품용기 3천원** | 효과음 한 번(펌프) |
| 2.5~6 | 클렌저 원액을 용기에 붓는 장면 | 클렌저 원액을 이만큼만 | 나레이션 시작 |
| 6~12 | 물 채우고 흔드는 장면 | **물 채우고 흔들면 끝** | |
| 12~18 | 펌프 눌러 거품이 손에 가득 | 거품이 이렇게 나옵니다 | |
| 18~25 | 세안하는 장면 | **원액 그대로 쓰면 반년 쓸 걸 두 달에 씁니다** | 강조 |
| 25~30 | 용기 두 개 나란히 (전/후) | 3천원으로 클렌저 값 절반 | |
| 30~33 | 제품 정지컷 + 텍스트 | **다이소 · 링크는 설명란** | 마무리 |

### 소재 (전부 상업적 사용 가능)
확보 완료 — Pexels 세로 영상:
- `foam soap dispenser` 11초 / 12초 (2160×3840)

**직접 찍으면 더 좋다.** 다이소에서 사서 손으로 펌프 누르는 3초만 찍어도 스톡보다 훨씬 잘 먹힌다.

## 3. 접시선반 — "활용법 N가지"

### 근거
- 효율 445 · 45만 · 42초 — "다이소에서 **이거 하나만** 사세요… **활용법 4가지** 알려드릴게요"
- 효율 320 · 175만 · 21초 — "수납함 활용능력 높여주는 추천템"
- 효율 297 · 562만 · 29초 — "다이소에서 **품절된 7가지**"

→ **개수를 박고, 한 물건의 여러 쓰임을 보여주는 구조.**

### 제목 후보 10개
1. 다이소 접시선반 하나로 끝나는 수납 4가지
2. 다이소에서 이거 보이면 무조건 두 개 사세요
3. 접시선반, 접시 말고 여기 쓰면 더 좋습니다
4. 싱크대 좁은 집 필수템 3천원짜리
5. 상부장 공간 두 배 만드는 다이소 선반
6. 다이소 접시선반 활용법 5가지
7. 좁은 주방 살리는 다이소 수납템 TOP3
8. 이거 하나로 그릇 쌓아두는 습관 고쳤습니다
9. 다이소 선반 하나에 3천원, 공간은 두 배
10. 주방 정리 못 하는 사람이 꼭 사야 할 것

> 1·6·7·9번이 공식에 가장 가깝다(숫자 + 단정형).

### 33초 구성표

| 초 | 화면 | 자막 | 소리 |
|---|---|---|---|
| 0~3 | **그릇이 아슬아슬하게 쌓인 싱크대** (문제 장면) | **이렇게 쌓아두고 계시죠** | 훅 |
| 3~7 | 접시선반 꺼내 놓는 장면 | 다이소 3천원 | |
| 7~13 | ① 접시 세우기 | **① 접시 — 공간 두 배** | |
| 13~19 | ② 냄비뚜껑 꽂기 | **② 냄비뚜껑 — 이게 진짜** | |
| 19~25 | ③ 도마·프라이팬 세우기 | **③ 도마·팬** | |
| 25~30 | ④ 밀폐용기 뚜껑을 칸마다 꽂기 | **④ 뚜껑 — 여기가 백미** | |
| 30~33 | 정리된 싱크대 전체 + 제품컷 | 다이소 · 링크는 설명란 | 마무리 |

> ⚠️ **처음 쓴 구성표는 틀렸다.** ④를 "상부장 통조림 정리"로 잡았는데, 그건 2단 선반형이고
> ①②③은 접시 꽂이형이다. **한 제품으로 네 컷이 안 나온다.** 꽂이형이 셋을 커버하므로 그쪽으로 가고
> ④를 밀폐용기 뚜껑으로 바꿨다. 뚜껑 굴러다니는 건 주방 쓰는 사람 공통 불만이라 저장·공유가 잘 나온다.

**0~3초가 전부다.** "정리된 모습"이 아니라 **"엉망인 모습"으로 시작해야** 손가락이 멈춘다. 상위 영상 전부 문제 장면으로 열었다.

## 4. 만들기 전에 반드시

1. **쿠팡 파트너스 승인 + 인증키** — 없으면 링크를 못 걸고, 조회수가 나와도 0원이다
   `.env`의 `COUPANG_ACCESS_KEY` / `COUPANG_SECRET_KEY` (현재 둘 다 비어 있음)
2. **쿠팡에 같은 물건이 있는지 확인** — 키가 들어오면 `coupangPartners.checkSellable()`이 자동으로 본다
3. **대가성 문구** — 쿠팡 제휴는 표시가 법적 의무다. `affiliateLink.js`의 `DISCLOSURE`가 링크에 자동으로 따라붙는다
