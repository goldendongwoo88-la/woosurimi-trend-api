## 1. 자동컷·자동캡션 붙이기

작업실 사이드바에 메뉴가 **이미 있습니다.** 그 뒤에 파이썬 엔진을 연결하면 됩니다.

### 파일 받기

```powershell
git clone --depth 1 https://github.com/goldendongwoo88-la/woosurimi-trend-api.git _tmp
Copy-Item _tmp\goldencut\* .
Remove-Item -Recurse -Force _tmp
```

`goldencut_effects.py` / `goldencut_caption.py` / `goldencut_voice.py` 3개입니다.
pip 설치 필요 없고 ffmpeg만 있으면 됩니다.

### 호출 방법 — `--json`으로 부르면 결과를 프로그램이 그대로 받습니다

```
python goldencut_effects.py --scenes-json scenes.json --out out.mp4 \
  --effect whitecard-pop --hook "제목" --seconds 15 --voice golden --json
```

**stdout에는 결과 JSON 한 줄만** 나옵니다(진행 문구는 stderr로 보냅니다). 그래서 호출한
쪽은 stdout만 파싱하면 됩니다.

```json
{"ok": true, "path": "out.mp4", "duration": 15.53, "effect": "whitecard-pop",
 "label": "화이트카드 팝", "scenes": 4, "voice": "골든 목소리"}
```

실패해도 같은 모양입니다: `{"ok": false, "error": "..."}`

효과 목록도 JSON으로 받을 수 있습니다 — 화면 드롭다운을 이걸로 채우세요:

```
python goldencut_effects.py --list --json
```

`scenes.json` — **사진과 영상을 섞어서** 넣습니다:

```json
[
  {"image": "clip1.mp4", "caption": "영상은 *좋은 구간*을 알아서 골라요"},
  {"image": "photo.jpg", "caption": "사진과 *섞어* 써도 됩니다"}
]
```

`*별표*`로 감싼 부분만 강조색으로 나옵니다(한 줄 통째로 칠하지 않는 게 요즘 숏폼 기본).

### 화면에 둘 것

| 항목 | 값 |
|---|---|
| 화면 효과 | `--list --json`으로 받은 6종 |
| 길이 | 15초 / 28초 / 자동 |
| 목소리 | 골든 / 차수리미 / 음성 없이 자막만 |
| 인트로 | 흩뿌린 사진 (켬/끔) |

### 더빙 준비

```
VOICEBOX_PROFILE_GOLDEN=<골든 보이스 id>
VOICEBOX_PROFILE_CHASURIMI=<차수리미 보이스 id>
```

id 확인: `python goldencut_voice.py --check`

### 자동 캡션

```
python goldencut_caption.py --video in.mp4 --out out.mp4
```

단어별 강조가 기본입니다. 받아쓰기는 `pip install faster-whisper`가 가장 쉽습니다.

## 2. 유튜브 파인더 붙이기

"구독자는 적은데 조회수는 터진" 영상을 찾는 기능입니다. **이미 만들어져 있습니다** —
woosurimi 서버를 켜고 API만 부르면 됩니다.

```powershell
cd <woosurimi-trend-api 폴더>
npm install
npm start          # 기본 3000번
```

| 용도 | 호출 |
|---|---|
| 상태·엔진 확인 | `GET /api/finder/status` |
| 화면 통째로 쓰기 | `http://localhost:3000/youtube-finder.html` |

⚠️ `YOUTUBE_API_KEY`가 있으면 유튜브 API로 빠르게, 없으면 yt-dlp로 느리지만 키 없이
돕니다. 둘 다 무료입니다.

**가장 빠른 방법:** 작업실 메뉴에서 그 화면을 iframe으로 띄우는 것부터 하세요. 화면을
새로 만들지 말고 붙여만 놔도 "하나의 앱"이 됩니다. 나중에 필요하면 API만 불러서 작업실
디자인으로 다시 그리면 됩니다.

## 3. 순서

1. woosurimi 서버를 **포트 하나로** 켠다 (8489·8486 따로 켜지 않기)
2. 작업실에 **유튜브 파인더** 붙이기 (iframe — 제일 쉬움)
3. 작업실 **자동컷·자동캡션**에 파이썬 엔진 연결 (`--json` 호출)
4. 골든컷(18741) 끄기
5. 링크로 영상 만들기 → woosurimi 서버 API로 연결

## 알려진 함정 (실제로 겪은 것들)

- **영상+사진을 섞으면 전환이 깨졌습니다.** 타임베이스가 달라서인데
  (`timebase (1/12288) do not match (1/15360)`), `settb/asettb`로 맞춰서 고쳤습니다.
  직접 xfade를 쓰실 거면 같은 처리가 필요합니다.
- **자막은 `.srt`가 아니라 `.ass`로** 만들어야 합니다. `.srt`에 색 태그를 넣으면
  ffmpeg가 먹어버립니다.
- **`-shortest`를 쓰면 안 됩니다.** 나레이션이 장면보다 짧을 때 장면이 잘려서 전환
  offset이 어긋나고 영상이 통째로 깨집니다. `-af apad` + `-t`로 길이를 못박으세요.
- **출력은 1080×1920 / 30fps.** 서버판이 720×1280인 건 Render 메모리 한계 때문이고
  로컬은 그럴 이유가 없습니다.
