## 1. 무편집 유튜브 (6편) — ⭐ 가장 값어치 있던 주제

영화·드라마·해외 영상을 편집해서 올리는 라인. 6편이 **서로 다른 사람인데 같은 규칙**을 말합니다.

### 저작권 — 6편이 공통으로 말한 것

| 규칙 | 출처 | 우리 코드 반영 |
|---|---|---|
| **경고 3회 = 채널 삭제.** 유튜브는 위반 5~10개를 묶어 경고 1회로 준다 | 배워야산다, 드라마쇼츠 | screener.js 없음 |
| **원본과 달라질수록 알고리즘이 저작권을 못 잡는다** → 컷을 최대한 잘게 | 드라마쇼츠 | 없음 |
| **유튜브 공식 수익창출 기준 = "오디오·시각 효과를 더한 실질적 편집"** — 재해석 3요소(나레이션·자막·효과)를 다 넣어야 함 | N잡학교 | 없음 |
| **나레이션 자막은 다른 색·다른 폰트**로 — 항소할 때 "이건 내 창작"이라는 증빙이 된다 | 드라마쇼츠 | 없음 |
| **AI·재사용 콘텐츠는 수익창출 불가**가 정책에 명시돼 있다 | 6억 레오 | 없음 |
| **배급사마다 대응이 다르다** — 홍보로 보고 방치 vs 즉시 조치. 배급사별로 분류해두면 리스크가 줄어든다 | 드라마쇼츠 | 없음 |
| **토렌트 절대 금지.** P2P 제휴 다운로드(금액 일부가 원작자에게 감)가 그나마 안전 | 배워야산다 | 없음 |
| **판단 기준: "이 감독이 내 쇼츠를 보고 좋아할까, 불편해할까"** | 배워야산다 | 없음 |
| TTS를 기본값 그대로 쓰지 말 것 — 감정·톤·배속(1.4배) 변경 | N잡학교 | 없음 |
| 소스 10~20개를 섞어라. **저작권이 아니라 중복도 때문** | 부업부자 | 없음 |

### 숫자 (검증용)

- 수익창출 요건: **구독자 1,000명 + 쇼츠 91일 내 누적 1,000만 조회**
- 드라마쇼츠 RPM: **조회 1,000당 0.3원** — 단가가 낮아 양으로 승부하는 판
- 배워야산다: 첫 달 350만 → 2개월차부터 월 1,000만 이상 (3년 운영)
- 월록남(7억): 채널 150개 보유 → **30~40개 운영, 하루 60~70편 발행**, 폰 여러 대로 모바일 업로드
- 레오(6억): 메인 7 + 테스트 6 = 13채널, 하루 30~70편. 음원 수익만 누적 2억
- 박준휘(20억): 16초 쇼츠를 **15분에 제작** → 642만 조회. 조회수 수익 + 쿠팡 쇼핑 수익 **이중 구조**

### 우리가 가져올 것

`gw_global_shorts_2026/screener.js`는 "이 소스를 써도 되나"만 봅니다.
**"어떻게 고쳐야 안전해지나"가 빠져 있습니다.** → 2번 항목으로 만듭니다.

### 제품 선정 기준 (부업부자)

1. **내 팔로워가 기대하는 결이어야 한다** — 결이 다르면 팔로워가 먼저 이탈
2. **기능이 아니라 문제 해결이 명확한 것**

### 소싱 (민대표, 월 3억)

- 판매 플랫폼 6곳 분산 (루핀은 마진 40%, 일반 스마트스토어는 10~20%)

- 드랍쉬핑 권장 마진 **25%** (플랫폼 추천은 220%지만 과함)
- **중국 판매자 촬영 사진은 저작권 문제없이 사용 가능**

4. **조립 팀원**
5. **팀장** — 지금 몇 번째 팀원이 일하는지 한 줄로 보고
