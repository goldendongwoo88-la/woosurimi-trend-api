> **이 문서를 만든 이유**
>
> 사장님 PC에서 만들고 계신 GoldenCut(`C:\...\outputs\GoldenCut`, `http://127.0.0.1:18741/studio`)에
> 이 저장소의 쇼츠생성기 기능을 옮기는 중인데, **제가(원격 세션) 그 PC에 들어갈 수 없어서
> "제대로 옮겨졌는지"를 직접 확인해 드릴 수가 없습니다.**
>
> 그래서 대신 **옮겨야 할 것의 정답지**를 만들었습니다. 아래 숫자는 전부 이 저장소의
> 실제 동작 코드에서 그대로 뽑은 값입니다(추정치 아님). GoldenCut 쪽 세션에 이 문서를
> 그대로 주고 "이 값대로 맞춰졌는지 대조해줘"라고 하시면 됩니다.

## 0. 먼저 — 참고 영상과 현재 렌더러의 해상도가 다릅니다 ⚠️

| | 값 |
|---|---|
| 참고 영상 `22-충격뉴스형.mp4` | **1080×1920 / 30fps / 23.6초** |
| 참고 영상 `23-비교형.mp4` | **1080×1920 / 30fps / 26.1초** |
| 이 저장소 렌더러 출력 | **720×1280 / 25fps** |

이 저장소가 720×1280인 건 Render 무료/Starter 서버의 CPU·메모리 한계 때문입니다.
**GoldenCut은 사장님 PC에서 돌아가니 그 제약이 없습니다 — 1080×1920 / 30fps로 내보내세요.**
아래 픽셀 값들은 1280 높이 기준이므로, 1920으로 쓸 때는 **×1.5** 하시면 됩니다.

## 2. 자막 — 위치·크기 (가장 많이 틀리는 부분)

자막은 **두 겹**입니다. 이게 한국 숏폼의 기본 구성입니다.

| 겹 | 역할 | 위치 |
|---|---|---|
| Hook(후킹) | 영상 **내내 상단 고정**. 스크롤을 멈추게 하는 한 문장 | 상단 중앙 |
| Body(본문) | 장면마다 바뀌는 하단 멘트 | 하단 중앙 |

실측 픽셀값(참고 영상에서 잰 값):

| 항목 | 1280 높이 기준 | 1920 높이 기준(×1.5) |
|---|---|---|
| 후킹 글자 크기 | **약 71px** | 약 106px |
| 후킹 위쪽 여백(화면 위 → 글자) | **약 129px** | 약 194px |
| 본문 글자 크기 | **약 53px** | 약 80px |
| 본문 아래쪽 여백(화면 아래 → 글자) | **약 302px** | 약 453px |

⚠️ **ASS/libass로 만들 때 주의 2가지** — 둘 다 실제로 당해본 함정입니다.

1. `.srt`를 쓰면 안 됩니다. 핵심 단어만 색을 바꾸는 `{\c&H...&}` 태그를 ffmpeg의 subrip
   디코더가 먹어버립니다. **`.ass`로 만들어야** 색 태그가 살아납니다.
2. `BorderStyle=3`(불투명 박스)일 때 **박스 배경색은 `BackColour`가 아니라 `OutlineColour`**
   입니다. `BackColour`는 `BorderStyle=1`일 때 그림자 색으로만 쓰입니다.
3. Alignment 번호가 구식 SSA 방식입니다. **상단 중앙 = 6** (ASS v4+ 넘패드 방식의 8이 아님).
   하단 중앙 = 2.

자막 줄바꿈 규칙:

| 항목 | 값 |
|---|---|
| 한 줄 최대 글자 수 | **12자** |
| 한 화면에 띄우는 줄 수 | **2줄** |
| 2줄 한 덩어리당 최소 노출 시간 | **1.4초** |
| 후킹 한 줄 최대 글자 수 | 12자 |

→ 장면 최소 길이 = (자막 덩어리 개수) × 1.4초. 장면당 길이를 이보다 짧게 줘도
자동으로 늘어납니다(자막이 휙 지나가버리는 걸 막는 장치).

## 3. 강조색 — "요즘 숏폼"의 핵심

한 줄을 통째로 같은 색으로 쓰지 않습니다. **핵심 단어 한둘만** 색을 바꿉니다.
소리를 끄고 보는 사람이 많아서, 색 바뀐 단어만 훑어도 내용이 전달되게 하는 장치입니다.

대본에 `*별표*`로 감싼 부분을 강조색으로 바꿉니다. 템플릿별 강조색:

| 템플릿 | 본문 글자색 | 강조색 |
|---|---|---|
| bold-black (볼드 블랙) | 흰색 + 검은 반투명 박스 | **노랑** |
| soft-cream (감성 크림) | 짙은 회색 + 크림 박스 | 벽돌색 |
| neon-pink (네온 핑크) | 핑크 + 테두리만 | 하늘색 |
| vivid-yellow (비비드 옐로우) | 노랑 + 검은 박스 | 흰색 |
| clean-blue (클린 블루) | 흰색 + 블루 박스 | 노랑 |

## 4. 화면 효과팩 6종 (2026-09-18 신규)

`src/videoEffects.js`. **자막 디자인과 별개로 "화면"을 정하는 값**입니다.
캡컷 자동컷 영상 3편을 프레임 단위로 분석해 만들었습니다.

| id | 액자 | 컷 간격 | 전환 | 색보정 | 어울리는 소재 |
|---|---|---|---|---|---|
| `clean-zoom` | 꽉 채우기 | 3.2초 | 하드컷 | 없음 | 기본값(정보·리뷰) |
| `photocard-drift` | 하얀 카드 + 흐린 배경 | 2.8초 | fade/dissolve | 채도 +6% | 감성·매장 소개 |
| `whitecard-pop` | 하얀 카드 + 밝은 단색 배경 | **1.9초** | slideleft/right | 대비+채도 ↑ | 제품컷 빠르게 |
| `vivid-punch` | 꽉 채우기 | 2.2초 | hblur/fadewhite/zoomin/pixelize | 채도 +34%, 샤픈 | 세일·후킹 |
| `film-strip` | 시네마 레터박스 | 3.6초 | fadeblack/dissolve | 채도 −26% | 사주·스토리 |
| `soft-bloom` | 꽉 채우기 | 3.0초 | circleopen/close | 밝기 ↑, 소프트 | 뷰티·웨딩 |

측정 근거: 신발 편 실측 컷 간격 **1.29초**(음악 박자에 맞춘 규칙적 컷) →
나레이션 여유를 더해 `whitecard-pop` 1.9초. 안마의자 편은 하얀 카드를 장면마다
반대 방향으로 살짝 기울였고(±1.6°), 그림자가 카드와 같은 각도로 따라갑니다.

액자 치수(720×1280 기준, 1920이면 ×1.5):

| 액자 | 사진 영역 | 흰 테두리 | 배경 | 그림자 |
|---|---|---|---|---|
| photocard | 640×980 | 20px | 같은 사진 `gblur=sigma=24` + 어둡게(밝기 −0.08, 채도 0.85) | blur 16:2, 알파 0.40 |
| whitecard | 580×880 | 24px | 단색 `#F2F2F4` | blur 12:2, 알파 0.26 |
| letterbox | 720×768 (가운데 띠) | 없음 | 검정 | 없음 |

카드는 화면 정중앙보다 **55px 위**에 둡니다(아래 자막 자리 확보).

⚠️ 기울기를 넣을 때 `rotate` 필터는 귀퉁이를 **검정으로 채우는 게 기본**입니다.
`format=rgba` → `rotate=각도:c=none:ow=rotw(각도):oh=roth(각도)` 순서로 해야
투명하게 빠지고 모서리도 안 잘립니다.

## 5. 영상 길이 맞추기 (15초 / 28초)

`/api/shortform/render`에 `targetSeconds`를 넘기면 장면당 길이를 자동 배분합니다.

```
장면당 길이 = max(targetSeconds / 장면수, 1.2초)
```

실측 결과(장면 4개, 나레이션 없음):

| 요청 | 실제 MP4 길이 | 핸드오프 허용 범위 | 판정 |
|---|---|---|---|
| `targetSeconds=15` | **14.21초** | 14~17초 | ✅ |
| `targetSeconds=28` | **26.58초** | 25~30초 | ✅ |

⚠️ **정확히 그 초가 나오지는 않습니다.** 자막이 길면 읽을 시간(2줄당 1.4초)이 필요하고,
나레이션이 있으면 말이 끝날 때까지 기다리기 때문에 계산값보다 길어질 수 있습니다.
"대략 그 길이"가 맞는 이해입니다.

## 6. 나레이션(TTS)

지원 제공자 5종 — 환경변수가 없으면 **나레이션만 빠지고 영상은 정상 생성**됩니다(서버가 죽지 않음).

| 제공자 | 필요한 환경변수 | 비고 |
|---|---|---|
| Voicebox (로컬·무료) | `VOICEBOX_PROFILE_ID` (+`VOICEBOX_URL`) | **크레딧 안 듦 — GoldenCut 기본값으로 권장** |
| 네이버 CLOVA | `CLOVA_VOICE_CLIENT_ID`/`_SECRET` | 유료 |
| 타입캐스트 | `TYPECAST_API_KEY` | 유료 |
| ElevenLabs | `ELEVENLABS_API_KEY` | 유료 |
| Azure Speech | `AZURE_SPEECH_KEY`/`_REGION` | 유료 |

나레이션 처리 규칙(이거 안 맞추면 영상이 깨집니다):

- 장면 길이 = `max(계산된 장면 길이, 나레이션 길이 + 0.4초)`
- **`-shortest`를 쓰면 안 됩니다.** 나레이션이 장면보다 짧으면 장면이 통째로 잘려서
  이어붙일 때 전환 offset이 틀어지고 영상이 깨집니다. **`-af apad` + `-t 장면길이`**로
  뒤를 무음으로 채워 길이를 못박으세요.
- Azure에서 목소리를 안 고르면 대본 내용으로 남/여를 판단해 자동 선택합니다.
  **장면마다가 아니라 영상 전체 기준으로 한 번만** 정해야 합니다(중간에 목소리가 바뀌면 어색).

## 8. 검수 기준 (이걸 통과해야 "됐다")

사장님 규칙대로, **최종 MP4를 실제로 보고·듣고** 확인해야 합니다.

```powershell
# 길이 확인
ffprobe -v error -show_entries format=duration -of default=nw=1:nk=1 "영상.mp4"

# 해상도·fps 확인
ffprobe -v error -show_entries stream=width,height,r_frame_rate -of default=nw=1 "영상.mp4"
```

눈으로 볼 것: 상단 큰 제목 / 검정 배경 + 흰·노랑 강조 / 장면 전환이 실제로 보이는지 /
자막 크기 / 초반부터 자막·더빙이 바로 나오는지 / 마지막 CTA.
