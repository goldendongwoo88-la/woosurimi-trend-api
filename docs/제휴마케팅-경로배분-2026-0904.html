제휴 마케팅 — 어디에 무엇을 붙일 것인가

우수리미 · 2026-09-04 · 객단가는 쿠팡 API 실매칭 34건에서 뽑은 값
한 줄
우리는 가장 비싼 물건을 파는 자산에 가장 낮은 요율을 붙여놨습니다. 우수리미 유튜브의 소재 객단가 중앙값은 129,000원인데 거기 붙은 게 15개 경로 중 공동 최하위인 쿠팡 3%입니다. 같은 소재에 토스 10%를 붙이면 건당 3,870원 → 12,900원, 3.3배입니다.

1. 근거 — 우리 소재의 진짜 객단가

기존 비교표는 객단가를 25,000원으로 고정해 요율만 비교합니다. 그런데 쿠팡 API로 실제 매칭한 우리 소재 34건을 재보니 값이 다릅니다.

항목값
매칭 소재34건
중앙값129,000원
평균255,024원
최저 ~ 최고1,860 ~ 1,540,000원
2만원 이상 비율91%

모델 기본값의 5.2배입니다. 로봇청소기·안마의자·이동식 TV·3D 프린터를 다루는 채널이라 당연한 결과인데, 이 사실이 경로 선택에 반영돼 있지 않았습니다.

2. 지렛대는 둘이고, 곱해집니다

지렛대배수근거
① 객단가 (무엇을 고르나)10.7배 네이버 브랜드커넥트 실물 16건 — 2만원 이상 12건 평균 5,986원 vs 미만 4건 평균 559원
② 요율 (어디에 거나)3.3배 쿠팡 3% → 토스·무신사·에이블리 10%
둘은 곱해집니다. 비싼 물건을 고르고 거기에 높은 요율을 붙이면 이론상 최대 35배입니다. ①이 ②보다 3배 큽니다 — 순서를 틀리면 안 됩니다. 요율 갈아타기부터 하지 말고 소재 선정 기준(객단가 2만원 문턱)을 먼저 넣습니다.

브랜드커넥트 실측에서 수수료 1등은 요율 1%짜리 아이폰(15,582원), 꼴찌는 요율 12%짜리 크레아틴(2,868원)이었습니다. 요율만 보면 정반대 결론이 납니다.

5. 🔴 토스는 26일짜리 창입니다

토스 쉐어링크 10%는 2026-09-30까지 프로모션이고 10월 이후 요율은 공개되지 않았습니다. 오늘(9/4) 기준 26일 남았습니다.

  • 이 값을 영구 수수료로 계획에 넣으면 안 됩니다
  • 26일 안에 실적을 만들어 봐야 10월에 남길지 뺄지 판단할 근거가 생깁니다
  • API 승인은 났고 키 발급만 남았습니다. 키 만들 때 호출 서버 IP를 같이 등록해야 합니다
  • 9월 말에 반드시 재확인 — 요율이 내려가면 경로 배분을 다시 짭니다

6. 확인이 필요한 것 — 여기 위에 계획을 쌓지 않았습니다

확인할 것왜 중요한가
토스 쉐어링크가 가전을 취급하나 10%가 우리 최대 자산에 적용되는지가 이 계획의 최대 변수입니다. 금융 앱이라 상품군이 제한적일 수 있습니다. 확인 전에는 1순위로 올리지 않았습니다
각 경로의 어트리뷰션 창 쿠팡의 24시간 조건이 다른 곳에도 있는지. 없다면 요율 차이만큼의 이득이 그만큼 상쇄됩니다
뷰티·패션·리빙 실제 객단가 가전만 실측했고 나머지 셋은 추정입니다. 첫 정산이 나오면 이 표를 덮어씁니다
한 설명란에 여러 제휴 링크를 넣어도 되나 각 사 약관 확인 필요. 클릭이 분산되는 문제도 있습니다
