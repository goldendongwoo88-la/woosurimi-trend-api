## 4. 오늘 밟은 함정 (다시 밟지 말 것)

1. **크롬을 `Stop-Process -Force`로 죽이면 네이버 로그인이 풀립니다.** 쿠키를 디스크에 못 쓰고 죽습니다. `close-chrome.ps1`(CloseMainWindow)로 닫습니다.
2. **"로그인 상태 유지"를 안 켜면 NID_AUT·NID_SES가 세션 쿠키**라 창 닫는 순간 사라집니다. 로그인 확인은 **쿠키 만료 시각이 있는지**까지 봐야 합니다. 주소만 보고 판정하면 거짓 양성이 납니다(`blog.naver.com/<ID>?Redirect=Write`는 로그아웃이어도 열립니다).
3. **JS 템플릿 리터럴의 프로필 경로는 역슬래시 두 개.** `C:\dev\...`로 쓰면 `\d`가 `d`가 되어 **엉뚱한 새 프로필**이 생기고 늘 로그아웃으로 보입니다. 오늘 `list.js`·`cookie-check.js`가 그랬습니다.
4. **임시저장 목록 선택자는 `[class*='list'] [class*='item']` + 날짜가 있는 것만.** `li`로 잡으면 도구막대 단추까지 셉니다(목록 0개인데 25개로 나옴).
5. **영상에서 카드를 꽉 채우면 좌우가 잘립니다.** 카드는 통째로 얹고 빈 곳은 흐린 배경으로 채웁니다.
6. **흐림 처리는 절반 해상도에서.** 원본 해상도로 하면 5장에 1분 넘게 걸립니다.
7. **아이콘 이름이 목록에 없으면 타일에 글자가 그대로 찍힙니다.**
8. **이미지 프롬프트에 소재를 두 개 합치면 엉뚱한 게 섞입니다** ("옆머리 정리" → 미용실 + 빨래 선반). 하나만 씁니다.
9. **bash 히어독에서 `\n`이 실제 줄바꿈으로 풀립니다.** JS에 정규식·이스케이프를 넣을 때는 `String.fromCharCode(10)`을 쓰거나 Write/Edit 도구를 씁니다.
