**3. 진입 장벽**
- 초기비용: 대부분 0원(핸드폰만)~4만원(영상6 통신판매업신고). 유료 툴(드레스·하이덕)은 가격 언급 없음.
- 필요계정: 인스타 계정으로 쓰레드 생성(영상5), 쿠팡파트너스 별도 가입, 토스쉐어링크는 API 키 발급 별도 필요(영상4).
- 걸리는 시간: 신규계정 인지작업 3~5일(영상5) → 수익화까지 영상3은 7~8개월 소요 후 안정화, 영상1 어머니 사례는 "하루 만에" 수익이라고만 주장(과정 절차 없음).
- 하루 게시 개수: 영상3 초반 하루1~3개, 영상2는 정해진 개수 없이 "틈날 때마다"(시간 텀도 불규칙하게).

**4. 돈이 실제로 어디서 나오는가**
- 쿠팡파트너스: 3%, 클릭 후 24시간 내 전체 구매 적립(영상1·2·3).
- 토스쉐어링크: 직간접 10%, 동일하게 24시간 귀속(영상4, 광고성 주장이라 수치 검증 안 됨).
- 공동구매 브로커리지(영상6): 업체와 개별 협상한 5~7% 커미션, 정산주기 2주.
- 협찬/원고료: 팔로워 3,000명부터 브랜드 협찬·원고료 수령 가능하다는 주장(영상3)[주장].

**5. 계정을 죽이는 행동 목록 (자막 근거 있는 것만)**
- 스아리/품앗이(인위적 좋아요·댓글·팔로우 교환) — 영상1·영상5.
- 신규 계정 첫 게시물부터 외부링크(쿠팡/토스) 삽입 — 영상5.
- 게시물 본문·댓글에 쿠팡/토스 링크를 조회수 확보 전에 반복 직부착 — 영상5.
- PC+모바일 등 다중 기기·IP에서 동시 로그인 — 영상5.
- 쿠팡 수수료 수령 고지문구 누락 — 영상2(쿠팡 계정 자체 박탈 가능성), 영상4(경고·정지 가능, 근거 약함).
- 기계적으로 일정한 시간 간격(예: 1시간/30분마다)으로 게시, 댓글 복붙 — 영상2가 반례로 강조("사람처럼" 불규칙하게).

**6. 가장 값어치 있는 1편과 이유**
[무료배포] "99%는 정지 당해요"(하입덕, flIOnTiKBlI) — 사용자가 던진 핵심 질문인 "링크를 어디에 어떻게 붙여야 계정이 안 죽는가"에 6편 중 유일하게 구체적 절차(신규계정 3~5일 인지작업 → 첫 글 외부링크 금지 → 조회수 확보 후 댓글 추가 또는 프로필 인포크링크 우회 → 다중기기 로그인 금지 → 저품질 시 3~5일 모바일 전용 회복)로 답한다. 나머지 5편은 대부분 "결과"(수익 인증·수수료율)를 자랑하는 인터뷰·광고 포맷이라 정지 회피 메커니즘이 없거나(영상2·3·4) 스레드 게시와 무관한 별도 사업모델(영상6)이다. 다만 조회수가 6편 중 가장 낮고(2,142회) 전자책+유료 툴 퍼널이 강하므로, 절차만 참고하고 수익 숫자(8회 정지, 월1,000만원 등)는 전부 [주장]으로 취급할 것.
