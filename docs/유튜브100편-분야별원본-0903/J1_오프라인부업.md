- **실제 절차**: 1. 외주 과외로 패션 지식 습득(약 1년) 2. 브랜드 런칭·사업자등록 3. 초기 2년 매출 0에 가까운 실패기 4. 전문인력 영입 5. 무신사 등 플랫폼 입점 6. 히트상품(가방) 리오더로 매출 급증 7. 일본 진출, 오프라인 매장(성수동) 확장
- **숫자**: 작년 매출 100억, 올해 목표 300억 [주장, 화면 인증 없음]. 초기 2년간 매출 0에 가까운 상태 언급. 순이익 수치는 전혀 언급 없음 → 매출만 언급, 순이익 구분 불명
- **필요 조건**: 사무실(10평~), 원단·생산비, 디지털 프린팅 기계 등 설비투자, 전문인력 채용, 도매시장(동대문) 네트워크, 사업자등록, 오프라인 매장 운영
- **함정/경고**: 브랜드 초기 2년간 매출 0 지속(생존 자체가 리스크), 외주업체의 대금 미지급 피해 경험, 자본 집약 구조라 실패 시 손실이 큼
- **온라인 전환 가능성**: 불가 — 생산·재고·매장 운영이 핵심이며 자본·인력·오프라인 공간이 절대적으로 필요
- **퍼널 여부**: 퍼널 X — 강의·자료 판매 없음, 개인 브랜드 성장 스토리 콘텐츠

## 분야 종합

### 1. 2편 이상에서 반복된 원칙
- **무재고 위탁 구조**가 반복 등장(자판기 영상, 카톡 공동구매, 건기식) — 초기 자본을 0에 가깝게 낮추는 공통 전략
- **AI로 콘텐츠·상세페이지 자동 생성**이 반복 등장(자판기 영상, AI음악, AI콘텐츠, 건기식) — 진입장벽을 낮추는 마케팅 포인트로 공통 활용
- **"무료 라이브/무료자료 → 유료강의 전환" 퍼널 구조**가 8편 중 6편에서 반복 — 실질적 수익모델은 강의·컨설팅 판매인 경우가 다수
- **매출과 순이익을 구분하지 않고 뭉뚱그려 제시**하는 패턴이 다수 영상에서 반복 — 검증 신뢰도를 낮추는 공통 요인
- **바닥까지 떨어진 실패담(빚, 파산)을 도입부 훅으로 사용**하는 패턴이 반복(카톡 공동구매 6억, 건기식 7억, 패션브랜드 2년 적자)

### 2. 자본이 필요한 모델 vs 시간만 필요한 모델

| 구분 | 영상 | 필요 자본 |
|---|---|---|
| 자본 필요형 | 패션브랜드(일리고) | 사무실·원단·설비·인력, 수천만원~ |
| 자본 필요형 | 과자 소분판매 | 사입비+포장비, 소액이나 지속 매입 필요 |
| 자본 필요형 | 건기식(제조 옵션) | OEM 30만원~ + 판매자격 교육비 |
| 자본 필요형 | 아마존 셀링 | 재고 사입비+FBA 창고비, 계정세팅 수개월 |
| 시간만 필요형 | 카톡 공동구매 | 무재고, 가정용 냉동고면 충분(단 배송 노동시간 필요) |
| 시간만 필요형 | 과일 위탁판매 | 주문 시 발주라 무재고, 자본 거의 0 |

| 시간만 필요형 | AI 콘텐츠+강의판매 | 구독료 수준, 본인 시간·기획력이 핵심자원 |

### 3. 우리 조건(재택·자본 최소·AI 자동화 보유·오프라인 공간/차량/인력 없음)에서의 가능 여부

**가능**
- AI 음악 플레이리스트 유튜브 — 완전 재택, 자본 최소, AI 툴 조합(수노+GPT+캡컷)이 우리가 보유한 AI·자동화 역량과 직접 일치. 저작권 유통 등록 절차만 추가로 익히면 재현 가능

**부분 가능**
- AI 콘텐츠(카드뉴스)+강의판매 — 콘텐츠 자동화는 가능하나, 최종 수익화가 "본인이 강사가 되어 강의를 판매"하는 구조라 신뢰·팔로워 축적이 선행돼야 함
- 아마존 셀링 — 재택 관리는 가능하나 해외 재고 사입·통관·FBA 물류라는 자본·실무 요건이 있어 AI·재택만으로 대체 불가
- 과일 위탁판매, 건기식 위탁판매 — 무재고 구조 자체는 재택형이나 오프라인 도매 소싱망이 우리에게 없고 제시 수치의 신뢰도도 낮아 그대로 채택하기 어려움

**불가**
- 카톡 공동구매 — 동네 직접배송이 핵심 구조라 오프라인 이동·지역 기반이 필수, 우리 조건과 정면 배치
- 과자 소분판매 — 실물 소분·포장·발송 등 물리노동이 핵심
- 패션 브랜드 — 생산·재고·매장이 핵심인 자본집약 사업

### 4. 수익 주장의 신뢰도 순위 (화면 인증이 있는 순)
1. 카톡 공동구매 — 국세청 매출자료 화면 제시(가장 공적인 서류형 인증) + 자체 프로그램 일매출 화면
2. 건기식 위탁판매 — 계정별 매출 화면 제시(플랫폼 자체 캡처, 세부 판독은 불완전)
3. AI 콘텐츠+강의판매 — 본인 화면(수익 대시보드 추정) 캡처 제시, 출처 명확치 않음
4. AI 음악 플레이리스트 — 유통 플랫폼(디스트로키드) 수익 화면 일부만 제시, 나머지는 구두 주장
5. 과일 위탁판매(자판기 영상) — 화면을 보여주긴 하나 자막상 숫자가 특정 불가
공동 하위(화면 인증 전혀 없음): 아마존 셀링, 과자 소분판매, 패션 브랜드

### 5. 가장 값어치 있는 1편
**카톡 공동구매(BYLQyKhxUBA)**. 8편 중 유일하게 국세청 매출자료라는 공적 서류를 화면으로 제시했고, 순이익률(평균 20%, 상품별 15~35%)까지 구체적으로 밝혔으며, 초기 투자금이 사실상 0원(무재고 위탁+가정용 냉동고)이라는 조건도 명확했다. 자본과 조건을 검증 가능한 수치로 제시한 유일한 사례라는 점에서, 그대로 재현할 수는 없어도(동네 직접배송이 핵심) "저자본 부업 구조"의 기준점으로 가장 값어치 있다.
