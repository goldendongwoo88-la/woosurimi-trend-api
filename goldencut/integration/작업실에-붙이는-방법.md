# 작업실(18762)에 자동컷·자동캡션 붙이기

> ## ⚠️ 골든컷 담당 세션과 겹치는 부분이 있습니다 (2026-09-18)
>
> 골든컷(18741)에 **"자동컷 · 추천 6종"** 화면이 이미 있고, 담당 세션이 계속 기능을
> 올리고 있습니다. 이 저장소의 아래 두 개는 **그것과 하는 일이 같습니다**:
>
> - `goldencut/integration/autocut.js` — 링크 1개 → 추천 영상 6개
> - `public/goldencut.html` — 그 화면
>
> **본체가 정해지기 전까지 이 두 개 위에 새 기능을 쌓지 마세요.** 한쪽을 접게 되면
> 그만큼이 버려집니다. 정해지면 이 상자를 지우고 한쪽을 정리합니다.
>
> **겹치지 않는 것 — 가져다 쓰셔도 됩니다:**
>
> | 파일 | 무엇 |
> |---|---|
> | `goldencut/*.py` | 엔진 본체. 골든컷이 복사해 쓰는 것 |
> | `goldencut/styles.json` | 스타일 프리셋 10종. **파이썬에서 그대로 읽힙니다** |
>
> `styles.json` 은 화면효과+자막디자인+배경음악+목소리+길이를 한 묶음으로 묶은 10종입니다.
> JS와 파이썬이 같은 값을 따로 들고 있으면 반드시 어긋나므로 한 벌만 두었습니다.
>
> ```python
> import json
> styles = json.load(open("goldencut/styles.json", encoding="utf-8"))
> for s in styles["styles"]:
>     print(s["label"], s["effect"], s["template"], s["bgm"], s["voice"], s["seconds"])
> ```


골든컷을 따로 켜지 않아도 되게, 작업실 안에서 바로 영상이 만들어지게 만드는 방법입니다.
**파일 2개 복사 + 코드 1줄**이면 끝납니다.

## 1단계 — 파일 복사

작업실 폴더에서 PowerShell을 열고:

```powershell
git clone --depth 1 https://github.com/goldendongwoo88-la/woosurimi-trend-api.git _tmp
mkdir goldencut -Force
Copy-Item _tmp\goldencut\*.py            goldencut\
Copy-Item _tmp\goldencut\integration     goldencut\ -Recurse -Force
Copy-Item _tmp\public\goldencut.html      public\
Remove-Item -Recurse -Force _tmp
```

복사되는 것:

```
goldencut\
  goldencut_effects.py       ← 영상 만들기 (효과 6종)
  goldencut_caption.py       ← 자동 캡션
  goldencut_voice.py         ← 더빙 (골든 / 차수리미)
  integration\
    goldencut-routes.js      ← 화면과 엔진을 잇는 다리
public\
  goldencut.html             ← 사람이 보는 화면
```

## 2단계 — 코드 한 줄 넣기

작업실 서버 파일(`server.js` / `app.js` / `index.js` — express `app`을 만드는 곳)에서,
`app`을 만든 **뒤에** 이 한 줄을 넣습니다:

```js
require("./goldencut/integration/goldencut-routes")(app);
```

JSON 본문을 읽는 줄이 아직 없다면 그 위에 함께 넣어주세요:

```js
app.use(express.json());
require("./goldencut/integration/goldencut-routes")(app);
```

express 말고 다른 건 설치할 게 없습니다.

## 화면 없이 직접 부르고 싶을 때 (API)

작업실의 다른 기능에서 영상 만들기를 부르고 싶으면 이렇게 씁니다.

| 하는 일 | 부르는 곳 |
|---|---|
| 쓸 수 있는 상태인지 | `GET /api/goldencut/status` |
| 효과 6종 목록 | `GET /api/goldencut/effects` |
| 폴더 안 영상·사진 목록 | `GET /api/goldencut/browse?dir=...` |
| 영상 만들기 시작 | `POST /api/goldencut/render` |
| 자막 넣기 시작 | `POST /api/goldencut/caption` |
| 진행 상황 묻기 | `GET /api/goldencut/job/<작업번호>` |
| 완성된 영상 재생 | `GET /api/goldencut/file/<작업번호>` |
| 목소리 연결 확인 | `GET /api/goldencut/voice-check` |

영상 만들기는 **작업번호를 먼저 돌려주고 뒤에서 돕니다.** 몇 분이 걸리는 일이라
응답을 붙들고 있으면 브라우저가 먼저 끊어버리기 때문입니다.

```js
// 1) 시작 — 바로 작업번호가 옵니다
const { jobId } = await fetch("/api/goldencut/render", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    scenes: [
      { image: "C:\\소재\\clip1.mp4", caption: "영상은 *좋은 구간*을 알아서 골라요" },
      { image: "C:\\소재\\photo.jpg", caption: "사진과 *섞어* 써도 됩니다" },
    ],
    effect: "whitecard-pop",   // /effects 에서 받은 id
    seconds: 15,               // 비우면 자동
    voice: "golden",           // golden / chasurimi / none
    hook: "이거 모르면 손해",    // 맨 위 큰 문구 (선택)
    intro: false,              // true면 흩뿌린 사진 인트로
  }),
}).then(r => r.json());

// 2) 끝날 때까지 물어봅니다
const timer = setInterval(async () => {
  const j = await fetch("/api/goldencut/job/" + jobId).then(r => r.json());
  if (j.status === "running") return console.log(j.latest);  // 진행 문구
  clearInterval(timer);
  if (j.status === "done") console.log("완성:", j.result.path);
  else console.error("실패:", j.result.error);
}, 1500);
```

`caption`에서 `*별표*`로 감싼 부분만 강조색으로 나옵니다.
한 줄을 통째로 칠하지 않는 게 요즘 숏폼 기본입니다.

### ⚠️ 낮춰서 만든 영상은 화면에 꼭 표시해 주세요

링크→추천 6개(`/from-url`)는 목소리나 배경음악을 못 쓰면 **없는 채로라도 만들어 냅니다.**
영상을 통째로 못 내주는 것보다 나으니까요. 대신 낮췄다는 사실이 **결과보다 먼저** 보여야
합니다. 안 그러면 사장님이 잘못된 상태를 정상으로 아시게 됩니다.

`GET /api/goldencut/job/<번호>` 응답에서 이 세 가지를 읽어 주세요:

| 필드 | 뜻 |
|---|---|
| `voiceNote` | 비어 있지 않으면 **6개 전부** 목소리 없이 만든 것입니다. 목록 위에 띄워 주세요 |
| `downgradedCount` | 낮춰서 만든 영상 개수 |
| `videos[i].downgraded` | 그 영상이 무엇을 낮췄는지 한 줄 (예: `목소리 없이 자막만 · 배경음악 'bright' 파일이 없습니다`) |

`videos[i].voice` 와 `videos[i].bgm` 도 **실제로 들어간 값**으로 덮어씁니다
(목소리를 못 썼으면 `"none"`, 배경음악이 없으면 `null`). 계획한 값이 아니라 결과값입니다.

## 알아두실 것

**내 컴퓨터에서만 돕니다.** 이 기능은 내 PC의 파일 목록을 보여주고 내 PC의 파일로 영상을
만듭니다. 작업실처럼 내 컴퓨터에서 도는 프로그램에서는 당연하고 안전하지만, 인터넷에 올린
서버에서 열려 있으면 남이 서버 파일을 들여다볼 수 있습니다. 그래서 **localhost에서 온 요청만**
받도록 잠가뒀습니다. 굳이 열어야 한다면 `GOLDENCUT_ALLOW_REMOTE=1`을 직접 켜야 합니다.

**바꿀 수 있는 설정** (필요할 때만, 대부분 그냥 두면 됩니다):

| 환경변수 | 기본값 | 쓸 일 |
|---|---|---|
| `GOLDENCUT_PYTHON` | 윈도우 `python` | 파이썬 실행 이름이 다를 때 (`py`, `python3.11` 등) |
| `GOLDENCUT_DIR` | 이 파일의 상위 폴더 | .py를 다른 곳에 뒀을 때 |
| `GOLDENCUT_WORK_DIR` | 임시폴더/goldencut-jobs | 결과물을 다른 데 쌓고 싶을 때 |
| `GOLDENCUT_ROOT` | (제한 없음) | 폴더 열어보기를 특정 폴더 아래로만 묶고 싶을 때 |

**결과 영상**은 `GOLDENCUT_WORK_DIR` 아래 작업번호 폴더에 `out.mp4`로 쌓이고, **6시간 뒤
자동으로 지워집니다.** 보관할 영상은 그 전에 옮겨두세요.

**출력 규격**은 1080×1920 / 30fps입니다.

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| "파이썬이 없습니다" | 설치할 때 **Add Python to PATH**를 안 켠 경우가 대부분입니다. 재설치하거나 `GOLDENCUT_PYTHON`에 전체 경로를 넣으세요 |
| "ffmpeg가 없습니다" | ffmpeg를 PATH에 넣고 작업실을 껐다 켜세요 |
| "엔진 파일을 … 에 복사하세요" | 1단계 복사가 덜 된 경우입니다. 그 경로에 `.py` 3개가 있는지 보세요 |
| 화면은 뜨는데 효과 목록이 안 채워짐 | 파이썬은 되는데 엔진 실행이 막힌 경우입니다. `python goldencut/goldencut_effects.py --list`를 직접 쳐보세요 |
| "골든컷은 내 컴퓨터에서만" | 다른 기기에서 접속한 경우입니다. 작업실을 띄운 그 PC에서 여세요 |
| 목소리가 안 나옴 | Voicebox가 꺼져 있거나 `.env`의 보이스 id가 비었습니다. `--check`로 확인하세요 |
