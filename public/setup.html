둘 다 무료이고, 하나만 받아도 그만큼은 바로 쓸 수 있습니다. 검색광고 쪽이 더 쉬우니 그것부터 받으시는 걸 권합니다.

① 네이버 검색광고 API무료

월간 검색량과 연관 키워드를 봅니다. 이게 있어야 "이 키워드를 몇 명이나 찾는가"를 알 수 있습니다.
  1. searchad.naver.com 에서 네이버 아이디로 로그인 광고를 집행하지 않아도 계정은 만들 수 있습니다. 카드 등록도 필요 없어요.
  2. 오른쪽 위 내 정보 옆의 계정 이름을 누르고 도구 → API 사용 관리 '광고 시스템' 화면으로 들어간 뒤에 상단 메뉴에 나옵니다.
  3. 네이버 검색광고 API 서비스 이용약관에 동의하고 등록
  4. 화면에 나오는 액세스 라이선스와 비밀키를 복사 비밀키는 등록할 때 한 번만 보여줍니다. 놓치면 다시 발급받아야 해요.
  5. 고객 ID(CUSTOMER_ID)는 같은 화면 위쪽이나 '내 정보'에 있는 숫자입니다 보통 일곱 자리 숫자예요.
# .env 파일에 이 세 줄을 넣으세요 NAVER_AD_API_KEY=여기에_액세스_라이선스 NAVER_AD_SECRET_KEY=여기에_비밀키 NAVER_AD_CUSTOMER_ID=여기에_고객ID

② 네이버 API HUB (검색)일정량 무료

블로그에 이미 글이 몇 개나 있는지, 오늘 몇 개가 올라왔는지, 상위 글이 어떻게 생겼는지를 봅니다. "경쟁이 얼마나 센가"를 아는 데 필요합니다.
  1. ncloud.com (네이버 클라우드 플랫폼) 가입 개인도 가입됩니다. 결제 수단 등록을 요구할 수 있는데, 검색 API는 무료 사용량 안에서 쓰면 요금이 안 나옵니다.
  2. 콘솔에서 Services → AI·NAVER API → Application
  3. Application 등록 → 이름을 아무거나 정하고, Search (검색) 항목을 체크 블로그 검색이 이 안에 들어 있습니다.
  4. 등록된 Application에서 인증 정보를 열어 Client ID와 Client Secret 복사
# .env 파일에 이 두 줄을 넣으세요 NAVER_APIHUB_KEY_ID=여기에_Client_ID NAVER_APIHUB_KEY_SECRET=여기에_Client_Secret
⚠️ 예전 developers.naver.com 경로로 발급받은 키는 안 됩니다. 네이버가 2026년부터 검색 API를 클라우드 플랫폼(API HUB)으로 옮겼고, 옛 경로로는 새로 발급이 안 됩니다.

받은 키를 어디에 넣나

사는 곳이 두 군데입니다. 둘 다 넣어두시면 편합니다.
  1. 이 PC에서 쓸 때 C:\Users\Admin\Desktop\my-project\woosurimi-trend-api\.env 파일을 메모장으로 열고 맨 아래에 붙여넣은 뒤 저장. 서버를 껐다 켜야 반영됩니다.
  2. 배포된 사이트에서 쓸 때 Render → woosurimi-trend-api → Environment → Add Environment Variable로 한 줄씩 넣고 Save. 자동으로 다시 배포됩니다.
⚠️ 이 키들은 비밀번호와 같습니다. 캡처해서 올리거나 남에게 보내지 마세요. .env 파일은 git에 올라가지 않도록 이미 막아뒀습니다.

키 없이도 되는 것들

키를 안 받으셔도 이건 그대로 씁니다.
  • 글 진단 — 글자 수·소제목·어미 반복·광고법 위험 표현
  • 고쳐쓰기 — 지적된 부분만 골라 고치기
  • 맞춤형 글쓰기 프롬프트 전부
  • 네이버 블로그 발행 도우미
  • 숏폼·카드뉴스 만들기
네이버 키가 필요한 건 키워드 진단과 상위 글 분석 둘뿐입니다. 글을 쓰고 다듬고 올리는 흐름은 키 없이도 전부 됩니다.
