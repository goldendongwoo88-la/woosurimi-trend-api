# 크롬 웹스토어 등록 — 사장님이 하실 것 (15분)

등록하면: 제가 고칠 때마다 **자동 업데이트**, 설정·토큰 **다시는 안 날아감**,
손님에게도 링크 하나로 배포. 비용은 **$5 한 번**(구글 개발자 등록비)뿐입니다.

## 순서

1. **개발자 등록** — https://chrome.google.com/webstore/devconsole
   구글 계정으로 로그인 → $5 결제 (카드) → 등록 완료
2. **새 항목 추가** → `store/업로드용.zip` 파일 업로드
3. **스토어 등록정보** 탭 — 아래 `등록정보.md` 내용을 그대로 붙여넣기
4. **스크린샷** — `store/` 폴더의 `shot-1.png`, `shot-2.png`, `shot-3.png` 업로드
5. **개인정보 보호** 탭:
   - 개인정보처리방침 URL: `https://woosurimi-trend-api.onrender.com/privacy-extension.html`
   - 데이터 사용 신고: `등록정보.md`의 "개인정보 신고" 부분 그대로
   - 권한 사유: `등록정보.md`의 "권한 사유" 부분 그대로
6. **심사 제출** — 보통 1~3일 걸립니다. 거절되면 사유가 메일로 오는데, 그대로 제게 보여주시면 고치겠습니다.

## 심사 통과 뒤

- 스토어 링크가 생깁니다. 기존 압축해제 버전은 **삭제**하고 스토어 버전으로 다시 설치하세요.
  (마지막 한 번만 토큰이 초기화됩니다 — 이후로는 영구히 유지)
- 다음부터 제가 새 버전을 올리면(제가 zip을 만들어 드리면 사장님이 대시보드에 업로드,
  또는 API 키를 설정하면 제가 자동 업로드 준비 가능) 크롬이 알아서 업데이트합니다.

## 주의

- 개발자 계정 이메일이 스토어에 **공개될 수 있습니다** — 공개용 이메일로 등록하세요.
- "테스터에게만 공개"로 먼저 올려서 사장님·사모님만 쓰다가, 나중에 "공개"로 바꿔 손님에게 열 수도 있습니다. **처음엔 '비공개(테스터)'를 권합니다.**
